# viz_revise_program

`docs/viz_revise/` 의 기획·스펙을 구현한 **AI:GO 스쿼드 트레이스 뷰어**다.
HTML 파일 하나. 설치·서버·인터넷 연결이 필요 없다.

**쓰는 법은 [`사용설명서.md`](사용설명서.md) 에 있다.**

---

## 바로 열기

```
trace-visualizer.html      ← 더블클릭
```

일부 브라우저가 `file://` 에서 폴더 읽기를 막는다. 그럴 때는:

```bash
python3 -m http.server 8777
# http://127.0.0.1:8777/viz_revise_program/trace-visualizer.html
```

## 고치는 법

```bash
# 1. 원본만 고친다
vi src/app.html

# 2. 검사를 통과해야 산출물이 나온다
bash tools/build.sh
```

**`trace-visualizer.html` 을 직접 고치지 않는다.** 산출물이라 다음 빌드에서 덮어써진다.

`build.sh` 는 복사 전에 12가지를 검사한다. 하나라도 걸리면 산출물을 안 만든다.

| 검사 | 무엇을 막나 |
|---|---|
| 외부 요청 0 | CDN·웹폰트·`fetch` — 오프라인 시연이 깨진다 |
| 글자 크기 토큰 7종 · 리터럴 0 | 타입 스케일이 다시 14종으로 번지는 것 |
| 4px 격자 | 5px·7px·9px 같은 그때그때 값 |
| `border-radius` 0 만 | 하드 엣지 규약 |
| 인라인 `style=` ≤ 20 | 색 규약을 CSS 가 아니라 JS 가 정하게 되는 것 |
| 이징 4종 · 키워드 금지 | 모션이 다시 제각각이 되는 것 |
| `@property --on` 존재 | 셀 게이지가 조용히 안 움직이게 되는 것 |
| 색 리터럴 금지 | 토큰 밖의 hex |
| **보존 구간 7개 바이트 동일** | **판정 로직이 바뀌는 것** |
| 명암비 | 텍스트 4.5:1 (고대비 7:1) · 인쇄 팔레트 포함 5개 블록 |
| JavaScript 문법 | — |
| 파일 크기 ≤ 400KB | — |

## 보존 구간

파싱·판정·집계·로드·내보내기 **1,105줄**은 개편 전 `viz/src/app.html` 에서
**바이트 그대로** 옮겼다. 소스에서 이렇게 감싸여 있다.

```js
/* @preserve:begin contract */
…
/* @preserve:end contract */
```

일곱 개다 — `contract` · `failure` · `collect` · `model` · `i18n` · `load` · `export`.
`build.sh` 가 매번 `.baseline/preserved/*.js` 와 `diff` 한다.

**이 안을 고치면 빌드가 거부한다.** 고쳐야 할 이유가 생겼다면 그건 UI 개편이 아니라
별개의 작업이고, 기준선을 다시 뜨는 결정을 먼저 해야 한다.

### 왜 이렇게까지 하나

이 뷰어의 값어치는 화면이 아니라 **판정**에 있다. 0점을 네 갈래로 가른 것,
`logs/index.json` 의 개수를 안 믿는 것, 에이전트별 토큰이 추정일 수밖에 없는 이유 —
전부 실제 로그를 파서 나온 것이다. 화면을 갈아엎다가 그 숫자가 한 자리라도 달라지면
개편이 아니라 손실이다.

회귀 검사는 한 줄이다. **같은 워크스페이스를 넣고 `JSON` 내보내기를 눌렀을 때
개편 전후의 파일이 바이트 동일해야 한다.** 실제로 확인했다 —
88,654 바이트, 해시 3646466680, 양쪽 동일 (`work_log/01-검증-결과.md` §1-1).

## 자동 시연

```
trace-visualizer.html#demo
```

폴더를 넣으면 60초 동안 스스로 돌면서 화면 아래 자막을 바꾼다. 1분짜리 영상을 찍는 데
사람이 클릭할 시간이 없어서 만들었다.

화면을 앱이 놓인 순서대로 훑고 각 화면을 위에서 아래까지 민다. 앵커로 튀지 않는다 —
튀면 그 사이에 무엇이 있었는지가 영상에서 사라진다.

0:30 에 보여줄 실행은 **id 로 고르지 않는다.** 촬영 데이터가 그때그때 다르기 때문에
"라우팅이 어긋났고 값은 맞은 실행" 같은 성격으로 찾고, 없으면 다음 후보로 내려간다.
어떤 워크스페이스를 넣어도 같은 이야기가 나오고 숫자만 그 데이터의 것으로 바뀐다.

자세한 것은 [`사용설명서.md` §15](사용설명서.md) 에 있다.

타이머로 민다 — `requestAnimationFrame` 은 탭이 뒤로 가면 아예 안 돌아서, 촬영 중 다른 창을
잠깐 만지면 슬라이더가 중간에 선 채로 남는다.
