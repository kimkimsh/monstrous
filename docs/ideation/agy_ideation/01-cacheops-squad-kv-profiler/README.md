# 주제 1: CacheOps-Squad & KV-Trace Profiler
> **"NPU 친화적 Prefix-Cache First 스쿼드와 서빙 레이어 KV 캐시 프로파일링 시스템"**

---

## 1. 한 줄 요약
**공통 프롬프트 및 60,000자 저장소 문맥을 프롬프트 최전방에 배치하여 서빙 스택의 Prefix Cache Hit율을 70% 이상으로 끌어올리는 스쿼드**와, **NPU(Furiosa RNGD) 레벨의 KV 캐시 재사용 현황을 실시간 프로파일링하는 인터랙티브 트레이스 시각화 도구**.

---

## 2. 기획 배경 및 문제의식 (Why)

1. **Coding 트랙(가중치 0.5)의 대규모 입력 토큰 병목**:
   - 코딩 문제마다 주최 측 채점기가 검색한 최대 60,000자(약 17,000 토큰)의 소스코드 컨텍스트 번들이 주입됩니다.
   - 4명의 에이전트가 순차 실행될 때, 잘못된 프롬프트 순서로는 문항당 $17,000 \times 4 = 68,000$ 토큰이 전부 신규 과금됩니다.
2. **제출 포털의 핵심 힌트 공략**:
   - 주최 측 포털 명시: *"길고 고정된 프리픽스를 앞에 두면 진짜 여유가 생긴다 (Cached input share)."*
   - 서빙 스택(Backend.AI Continuum Router 및 Furiosa NPU)은 앞부분이 동일한 요청에 대해 KV 캐시를 재활용하여 단가를 대폭 할인합니다.
3. **심사위원 관점 정밀 타격**:
   - Lablup(인프라 소프트웨어)과 FuriosaAI(NPU 하드웨어)가 가장 중요하게 평가하는 **"하드웨어 인프라 친화적 LLM 운영(TokenOps & Infra-Aware AI)"**을 정면으로 증명할 수 있습니다.

---

## 3. 스쿼드 아키텍처 (How - Squad Architecture)

### 📌 Prefix-Cache First 프롬프트 파이프라인
캐시 경계가 깨지지 않도록 모든 에이전트의 프롬프트 계층을 역발상으로 배치합니다.

```
┌────────────────────────────────────────────────────────┐
│ [Layer 1] 글로벌 공통 지시문 & 출력 계약 규약 (캐시 불변) │ ──▶ 전 문항 100% 캐시 히트
├────────────────────────────────────────────────────────┤
│ [Layer 2] 문항 저장소 컨텍스트 60,000자 (문항 내 불변)   │ ──▶ 문항 내 에이전트 간 100% 캐시 공유
├────────────────────────────────────────────────────────┤ ◀── [Cache Boundary (캐시 경계선)]
│ [Layer 3] 에이전트별 전용 역할 및 액션 지시 (가변, 초경량)│ ──▶ 50~100 토큰만 신규 계산
└────────────────────────────────────────────────────────┘
```

### 👥 에이전트 역할 구성
- **Cache-Planner**: 문항 종류(Coding/Math/MCQ) 식별 후 고정 캐시 템플릿 유지한 채 하위 태스크 디스패치
- **CodeReader**: 60k 컨텍스트에서 변경 대상 파일/라인의 위치 인덱스(`[start_line, end_line]`)만 초소형으로 출력
- **PatchWriter**: 인덱스된 위치 코드만 참조하여 표준 Unified Diff 생성
- **Verifier**: 문법 및 Diff 포맷 유효성 1회 검증
- **GiveUpJudge**: 불확실성이 높을 경우 1단어(`give_up`)로 즉시 중단하여 캐시 낭비 방지

## 4. 인터랙티브 트레이스 시각화 (Trace Visualization)

### 🖥️ `KV-Trace Profiler` 핵심 대시보드 화면
1. **Prefix Cache Hit Rate 히트맵**:
   - 364개 벤치마크 문항 및 에이전트 스텝별 Cache Hit/Miss 비율(0% → 72%) 실시간 시각화.
2. **NPU 메모리 & 지연 시간 절감 곡선**:
   - Furiosa RNGD 가속기 상에서 KV 캐시 재사용으로 인한 Time-to-First-Token(TTFT) 단축 및 메모리 절감량 지표 표기.
3. **토큰 비용 절감 누적 폭포수(Waterfall) 차트**:
   - Fresh Input 토큰 대비 Cached Input 토큰의 단가 차이로 인해 절약된 누적 USD 비용 실시간 계산.
