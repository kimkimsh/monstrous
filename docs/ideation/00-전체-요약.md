## 1. 트랙 (30초)

| 항목 | 값 |
|---|---|
| 산출물 | ① AI:GO Squad 기반 문제 해결 에이전트 스쿼드 ② 실행 Trace의 인터랙티브 시각화 |
| 필수 제약 | 문제 해결의 핵심부는 반드시 **AI:GO agent squad 기능** 위에 |
| 배점 | 벤치마크 **40** + 시각화 **30** + 토큰 효율 **30** |
| 총점 식 | `0.5×coding + 0.25×generic + 0.25×math` (가중치는 문항 수가 아니라 정확도 계수) |
| 제출물 | **Squad Template JSON 1개** + 트랙별 one-shot 프롬프트 3개 |
| 제출 제약 | 대기 3개 / 동시 실행 1개 · `check`는 무료 무제한 · 제출 1회 = 테스트 5회 비용 |
| 채점자 | **항상 프로그램.** LLM 심판 없음 |
| 동점 처리 | ① 총 토큰 적은 쪽 ② wall-clock 짧은 쪽 |
| 상금 | 1등 200만원, 2등 100만원 |

**세 트랙의 성격**

| | coding | math | generic |
|---|---|---|---|
| 가중치 | **0.50** | 0.25 | 0.25 |
| hidden 문항 | 140~240 | 60~66 (×2회 반복) | **448~698** |
| 문항당 입력 | **60,000자 컨텍스트 ≈ 17k 토큰** | ~150 토큰 | ~300 토큰 |
| 채점 | fail-to-pass + pass-to-pass | 최종 답 정확 대조 | 보기 문자 대조 |

**반드시 알아야 할 사실 6개**

1. **coding 출력 형식은 unified diff가 아니라 SEARCH/REPLACE 블록이다.**
   `*** PATCH START ***` / path 줄 / `<<<<<<< SEARCH` `=======` `>>>>>>> REPLACE` / `*** PATCH END ***`
2. 세 트랙 공통 규칙 — *"If more than one appears, the last one is used. Anything before it is ignored, not penalised."*
   → **응답 본문 앞부분은 감점 없는 자유 공간.**
3. **평가 실행 중 스쿼드는 도구가 없다.** 저장소를 뒤지지 않는다. judge가 60,000자로 잘라 넣어준다 (중앙값 59,966자 / 발췌 10개 / 후보 696개).
4. 평가 모델 3개 중 **2개가 reasoning 모델**이고 하나는 출력의 **97%를 사고 토큰**에 쓴다. 토큰 캡이 약 10배 세게 물린다. → instruct 기본, reasoning은 국소 투입.
5. **prefix cache** — 고정 프리픽스를 앞에, 변하는 부분을 뒤에. 저장소별 캐시는 무효(문항 간 재사용 django 2.7%, 나머지 0%). 이득은 **한 문항 안에서 여러 에이전트가 같은 60,000자를 볼 때만**.
6. 확인 모델 `Qwen3-30B-A3B-Instruct-2507-FP8` 단일 호출 기준선 — MMLU-Pro **78.4** / AIME25 **61.3** / LiveCodeBench v6 **43.2** / Aider-Polyglot **35.6**.
   → generic은 이미 잘한다. **coding 편집 형식이 최약점이자 최대 승부처.**

**시각화 6축**: observability · interpretability · traceability · explainability · clarity · **insightfulness**
앞의 다섯은 잘 만든 트레이스 뷰어면 채워진다. 승부는 insightfulness에서 난다.

## 2. 주제 16개 요약

### Claude 5개 — 규칙 허점과 비용 곡선

| # | 주제 | 한 줄 | 노리는 축 |
|---|---|---|---|
| C1 | **답은 맨 끝에** | 토론 과정을 채점되는 응답 본문 안에 적는다. 마지막 블록만 채점되므로 앞의 초안은 공짜. 계측 비용 0, "화면의 바이트 = 채점기가 읽은 바이트" | 시각화 (traceability) |
| C2 | **토큰 경제 스쿼드** | 스쿼드에 화폐 도입. 잔액 < 견적이면 파산 = 포기. 시각화는 트레이스 뷰어가 아니라 경제 대시보드. 단 s1 논문상 프롬프트 예산 지시는 안 통하므로 **하드 캡으로 강등** | 토큰 효율 |
| C3 | **확신도 계단** | 1단 거의 공짜 → 흔들릴 때만 2단(다수결) → 3단(thinking). 주인공은 정답률이 아니라 **캘리브레이션 곡선**. 고정 예산에서는 검증자보다 다수결이 낫다 | 효율 + 벤치마크 |
| C4 | **가지 않은 길** | 한 번 녹화하고 모델 없이 무한 재생. 심사위원이 슬라이더를 끌면 "포기를 2턴 앞당겼다면 −1.2%p / −38% 토큰"이 즉시 계산 | 시각화 (insightfulness) |
| C5 | **설계자와 편집자** | 점수의 절반인 coding 정조준. Architect(앵커만 낸다, 요약 금지) → Editor(SEARCH/REPLACE) → **Preflight(LLM 아님, 순수 프로그램)** | 벤치마크 |

### 최종 1개 — 이 셋을 합친 것

| # | 주제 | 내용 |
|---|---|---|
| **F** | **LEDGER Squad (장부를 쓰는 스쿼드)** | 15개를 하나로 합친 제출 주제 |

**구조** — 에이전트 5명 + 프로그램 1개
`Router`(Planner, 경로 배정) · `Architect`(coding 전용, 앵커만) · `Editor`(SEARCH/REPLACE) · `Solver`(math·generic 1턴) · `Auditor`(유일한 승급 호출) + `Preflight`(에이전트 아님, 순수 프로그램)

**네 기둥**

1. **검증은 프로그램이 한다** — Preflight가 마커 짝, SEARCH 문자열 실재, `\boxed{}` 모양, 보기 문자 범위를 LLM 호출 0회로 검사하고 **구체적 실패 지점**을 돌려준다.
2. **포기는 판단이 아니라 산수** — `max_tokens` 하드 캡 / AI:GO Budget Config(turns 20 → coding 6·math 3·generic 1) / 러너 산수(잔액 < 견적이면 호출 안 함). 전부 LLM 관여 0.
3. **장부를 답안 안에 쓴다** — 마지막 블록 앞은 채점 안 되므로 그 자리에 실행 기록. 계측 비용 0, "화면의 바이트 = 채점기가 읽은 바이트".
4. **무료 반사실 재생기** — 한 번 녹화, 무한 재생. 시도 횟수·예산·**에이전트 제거(무료 ablation)** 슬라이더가 정확도와 토큰을 재계산. 모델 호출 0회.

**프롬프트 3층** — `[공통 지시+출력계약+few-shot]` → `[문항 payload + 60,000자]` → **캐시 경계** → `[에이전트별 지시]`

## 3. 16개를 관통하는 합의점

- **에이전트를 늘리는 것 자체는 점수가 아니다.** 멀티 에이전트는 채팅의 약 15배 토큰을 쓰고 대부분의 코딩 과제에 잘 맞지 않는다(Anthropic). 늘릴 때마다 근거를 요구한다.
- **프로그램으로 되는 것은 프로그램이 한다.** 검증자도, 포기 판단도 LLM일 필요가 없다.
- **generic에서 아끼고, coding에서 캐시하고, math에서만 선별적으로 쓴다.**
- **토큰 효율은 두 번 작동한다** — 30점짜리 독립 축이면서 40점짜리 축의 동점 처리 1순위.
- **시각화의 승부는 insightfulness** — 심사위원이 직접 만져서 스스로 발견하게 만드는 화면.

## 4. 아직 확인 못 한 것

1. 평가 모델 3종의 정확한 이름과 **USD/Mtok 단가**
2. `per_run_token_cap` · `per_item_wallclock_seconds` 실제 값
3. one-shot 프롬프트가 스쿼드에 **어떻게 주입되는가** (planner에게만? 전원에게?)
4. "1/5로 과금되는 test run"의 정확한 정의 (PDF와 포털 설명 불일치)
5. Trace 로그 확보 경로 — 포털 `breakdown`은 문항 단위로 안 쪼개진다
6. **평가 실행 중 러너 레벨 검사·재시도가 가능한가** ← Preflight의 사활이 걸림
