# 00. 현행 viz 해부 — 어디까지가 로직이고 어디부터가 UI인가

대상: `viz/src/app.html` (3,761줄, 단일 HTML 파일) · 산출물 `viz/trace-visualizer.html` (동일 내용)
빌드: `viz/tools/build.sh` (32줄) — 복사 + 외부 요청·잔재 마커 검사
보조: `viz/tools/snapshot-logs.sh` (86줄) — 실행 중 로그 스냅샷

이 문서의 목적은 하나다. **재작성할 때 무엇을 그대로 두고 무엇을 버릴지를 줄 번호로 확정하는 것.**

## 2. 보존 대상 — 손대면 안 되는 것

### 2-1. 출력 계약 판정기 (`app.html:539-780`)

이 뷰어의 존재 이유 그 자체다. 심사 대상 화면이 아니라 **판정의 근거**이므로 재작성 대상이 아니다.

| 심볼 | 줄 | 하는 일 |
|---|---|---|
| `PS` / `PE` | 544 | `*** PATCH START ***` / `*** PATCH END ***` 리터럴 |
| `TRACK` | 558 | coding·math·generic·unknown 네 트랙 정의와 각 트랙의 계약 |
| `trackOf(request)` | 564 | 요청 지문의 생김새로 트랙을 찍는다. **계약 절이 잘려 나간 지문도 잡는다** |
| `CONTRACT` / `REQOUT` / `REAL_CONTRACT` | 585-595 | patch·boxed·letter + missing·unknown 두 상태 |
| `contractOf(request)` | 596 | 지문에서 출력 계약을 읽는다 |
| `optionsOf(request)` | 615 | 객관식 보기 목록 (`Options:` 절의 `A.`…`J.`) |
| `inspectLetter(text,options)` | 640 | `ANSWER: <letter>` 계약 검사 4종 + `near` / `hint` 근접 판정 |
| `verdictOf(e)` | 702 | 판정 한 줄. **분기가 여기 한 곳에만 있다** |
| `lastBoxed(t)` | 713 | 중첩 중괄호를 짝으로 세어 마지막 `\boxed{}` 를 읽는다 |
| `inspectBoxed(text)` | 724 | `FINAL ANSWER: \boxed{}` 계약 검사 |
| `inspectAnswer(text,kind,options)` | 745 | 계약별 분배 + patch 계약 검사 (마커·SEARCH/REPLACE 짝·경로 줄) |

**주의 — 여기에 UI 문구가 섞여 있다.** `inspectLetter` 의 `checks[].k` (`"ANSWER: 줄"`), `.d` (`"없음. judge 가 추출할 것이 없습니다"`) 는 화면에 그대로 나가는 한국어다. 문구를 키로 빼면 판정 로직이 바뀐다.

> **결정: 문자열도 함께 보존한다.** 번역은 지금처럼 i18n 사전이 담당한다. 판정기를 건드릴 이유가 UI 개편에는 없다.

`phasesOf` (1268) 가 돌려주는 위상 이름 `"플래닝" · "승인 대기" · "실행" · "집계"` 도 마찬가지다. `paneCmp` 가 `p.k==="실행"` 으로 비교하므로(2447) **이 문자열은 사실상 열거형이다.** 화면 표기는 `PHASE_EN` 과 `tp()` 로만 바꾼다.

### 2-2. 수집기 (`app.html:799-960`)

`addFile(path,name,text)` 하나가 파일 이름·경로만 보고 8종을 갈라 담는다. 확장자가 아니라 **내용을 시도해 보고 실패하면 다음 판별로 넘기는** 구조라 순서가 곧 규칙이다.

```
history.json → events.jsonl → logs/index.json → tasks/index.json
→ artifacts/reports/*.md → .squad.json(JSON.parse 시도) → tasks/*.md
→ tasks/*.json → artifacts/* → <executionId>.jsonl
```

`.squad.json` 판별이 `JSON.parse` 성공 + `agents` 배열 존재로 되어 있어서(897-899), **파일 이름이 달라도 스쿼드 설정을 알아본다.** 이건 의도된 유연성이라 유지한다.

`wsOf(path)` (822) 가 경로에서 워크스페이스 이름을 뽑는다. 여러 스쿼드 워크스페이스를 한꺼번에 넣는 기능의 뿌리다.

### 2-3. 모델 조립 (`app.html:962-1278`)

`build()` 하나가 실행 객체 배열 `S.execs` 를 만든다. 이 안에 뷰어의 관측 자산이 전부 들어 있다.

- **고아 이벤트 귀속** (999-1015): `executionId` 가 없는 이벤트를 `taskId` → 시간창 순으로 실행에 붙인다. 실측 50개 중 23개가 여기 해당한다.
- **태스크 구간 3단 폴백** (1041-1082): 이벤트 → 원문 로그 문장 → `completedAt - durationMs`.
- **토큰 귀속 추정** (1097-1113): 누적 곡선의 증분을 그 시각에 돌던 태스크에 준다. **동시 실행 구간은 나누지 않고 미귀속으로 남긴다.**
- **웨이브 구간 닫기** (1155-1170): 시작은 `events.jsonl`, 끝은 `<executionId>.jsonl`. 두 파일을 합쳐야 띠가 닫힌다.
- **`blocker` 4분류** (1136-1146): `blocked` / `nocontract` / `unknown` / `markers`. **이 네 갈래가 이 뷰어의 논지 전부다.**

`buildRoster()` (1215) 는 `squadId` 로 묶는다. 워크스페이스 하나에 스쿼드가 여럿일 수 있다는 실측(ikkim 한 폴더에 4개)을 반영한 자리다.

### 2-4. 인프라

| 심볼 | 줄 | 왜 남기나 |
|---|---|---|
| `readText(file)` | 3411 | `FileReader` 가 콜백을 안 부르는 경우까지 막은 코드. 타임아웃 20초 |

## 3. 폐기 대상 — 왜 남길 수 없나

### 3-1. `<style>` 383줄

토큰 체계가 없다. 자세한 측정은 `01-UX-결함-목록.md`.

### 3-2. 렌더 함수 1,470줄

`paneOverview` (2045) 부터 `paneRaw` (3340) 까지 전부 **템플릿 문자열로 HTML을 조립**한다. 문제는 문법이 아니라 **계산과 표현이 한 문장 안에 섞여 있다**는 것이다.

```js
// app.html:2075 — 값 계산 · 색 결정 · 마크업이 한 줄에
<td class="n"${wait&&wait>10000?' style="color:var(--warn)"':""}>${wait?secs(wait):"—"}</td>
```

`10000` 이라는 임계값이 렌더 함수 안에만 있다. 같은 임계값이 타임라인 탭에도 필요한데 거기서는 다시 쓰였다(3259). **표현을 바꾸려면 로직을 다시 읽어야 하는 구조**라, 이번처럼 UI만 갈아엎는 작업에서 가장 비싼 부분이다.

> **개편 방침: 렌더 함수는 버리되, 그 안의 계산은 순수 함수로 끌어낸다.** 임계값은 상수로, 색 결정은 토큰 매핑 함수로. 이렇게 하면 다음 개편에서 UI만 다시 갈아엎을 수 있다.

### 3-3. 살려야 하는 계산 — 렌더 함수 안에 숨어 있는 것

버리기 전에 반드시 추출할 목록이다. 이것들은 로그를 읽어 만든 **판단**이라 새로 쓰면 값이 달라진다.

| 계산 | 현재 위치 | 무엇을 만드나 |
|---|---|---|
| 판정 가능 분모 `ran` | `renderHeader` 1903 · `runSummaryCard` 1993 | `UNDECIDED` 3종을 뺀 모수. **비율은 이 위에서만 낸다** |
| 낭비 사분면 절약·손실 계산 | `drawWaste` 2348-2359 | 상한 슬라이더에 대한 절약 토큰·잃는 적격·잘리는 실행 |

## 4. 빌드와 배포 제약

`viz/tools/build.sh` 가 검사하는 것 두 가지:

1. **외부 요청 0** — CDN·폰트·이미지·`fetch` 전부 금지. 시연 환경이 오프라인일 수 있다.
2. **잔재 마커 없음** — 개발 중 표시가 산출물에 남지 않게.

여기서 나오는 하드 제약:

- **웹폰트를 링크로 못 쓴다.** 쓰려면 base64로 파일 안에 넣어야 한다.
- **차트 라이브러리를 못 쓴다.** D3·Observable Plot 전부 불가. SVG를 직접 만든다.
- **빌드 도구가 없다.** 전처리기·번들러 없이 손으로 쓴 CSS·JS 한 파일.

이 셋은 개편 뒤에도 유지한다. **파일 하나를 더블클릭하면 열린다**는 성질이 시연 리스크를 0으로 만드는 이 도구의 가장 큰 자산이다.
