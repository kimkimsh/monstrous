# 02. 화면 설계 — 무엇을 어디에 놓는가

와이어프레임은 비율만 나타낸다. 정확한 px·색·시간은 `../spec/`.

기호: `▓` 채운 셀 · `░` 빈 셀 · `▮` 도트 아바타 · `[ ]` 버튼 · `◆` 판정 도장

---

## 0. 공통 — HUD 두 띠, 97px

현행 3층(실측 `header` 62.1 + `.modes` 47.1 + `.tabs` 49.1 = **158.3px**)을 **두 띠 97px**로 합친다.

```
┌────────────────────────────────────────────────────────────────────────────────────┐
│ ▮MONSTROUS   실행 28   AI:GO 성공 19 ⇄ 채점 적격 6   CREDITS 1.24M ▓▓▓▓▓▓░░  TIME 32m │  56px
│  트레이스 뷰어  파일 109·스쿼드 3    두 판정이 갈린 13건   1칸 = 100k tok   평균 8.2s │
├────────────────────────────────────────────────────────────────────────────────────┤
│ [실행 하나][전체 분석][스쿼드 비교] │ [개요][▶재생][장부][타임라인][실패][원문]  🔍 검색 │  41px
└────────────────────────────────────────────────────────────────────────────────────┘
                                                    ko/en ◐ ⛶ SVG JSON 🖨 ↺ 는 띠 1 오른쪽
```

**계기는 라벨과 값이 같은 줄에 선다.** 세로 3줄로 쌓으면 계기 하나가 72.5px 이 되어
띠 하나가 90.9px 로 부푼다 — 실측으로 확인했고, 계산은 `../spec/01-컴포넌트-스펙.md` §16-0 에 있다.

**띠 2는 모드가 바뀌어도 높이가 안 변한다.** 「실행 하나」가 아닐 때 탭 6개는 `hidden` 이 되지만
띠는 41px 그대로다. 자리가 흔들리면 모드를 오갈 때 본문이 위아래로 튄다.

**TIME 은 `dur(ms)` 로 찍는다.** 현행 `secs()` 는 초만 내므로 28건 합계가 `1960.0s` 가 되고,
`fmt()` 는 개수용이라 `17.4M` 처럼 단위 없는 값을 낸다. 둘 다 여기 못 쓴다
(`../spec/03-화면별-스펙.md` §1-3).

### 0-1. 계기 4개 — 5개에서 줄인 이유

| 계기 | 내용 | 왜 |
|---|---|---|
| **실행** | 총 실행 수 + 파일·스쿼드 수 | 규모 |
| **AI:GO 성공 ⇄ 채점 적격** | 두 숫자를 **한 계기 안에** 나란히 + 갈린 건수 | **이 도구의 논점이 두 판정의 차이**다. 떨어뜨려 놓으면 논점이 사라진다 |
| **CREDITS** | 셀 게이지 + 실제 토큰 + 환산 비율 | 시그니처. 30점 축 |
| **TIME** | 총 wall-clock + 평균 | 동점 처리 2순위 |

`⇄` 기호와 그 아래 "두 판정이 갈린 13건" 이 대조를 명시한다. 갈린 건수가 0이면 `일치` 로 바뀌고 색이 LIME이 된다.

### 0-2. 크레딧 계기 상세

```
CREDITS  1.24M tok  ▓▓▓▓▓▓▓▓▓▓▓▓░░░░░░░░
                    └ 12/20 칸       1칸 = 100k tok
```

- 자리마다 칸 수가 다르다 — HUD 20 · 목록 행 12 · 패널 비교 16 · 격자 카드 8 (`../spec/01` §4-2).
- **칸당 토큰은 고정값이 아니라 총량에서 유도한다.** `총 토큰 / 칸 수` 를 유효숫자 1자리로
  올림한다 (`../spec/03` §1-1). 1.24M / 20 = 62k → `100k`.
- 절단선 실험 중: 잘려나간 칸이 **디더 패턴으로 남는다.** 사라지지 않는다.

```
CREDITS  ▓▓▓▓▓▓▓░▒▒▒▒░░░░░░░░  0.71M tok  ← 절단선 적용
                 └ 원래 값 (디더)          −0.53M
```

## 1. 오프닝 — 폴더를 놓기 전

현행 오프닝은 이미 좋다 (배경 흐르는 스쿼드 맵 + 카드 4장 + 언어 선택). **구조를 유지하고 표현만 바꾼다.**

```
┌────────────────────────────────────────────────────────────────────┐
│                                                          [ko / en] │
│                                                                    │
│        ▮▮▮▮  M O N S T R O U S                                     │
│              AI:GO SQUAD TRACE VIEWER                              │
│                                                                    │
│        ┌──────────────────────────────────────────┐                │
│        │  ▶ INSERT WORKSPACE                      │  ← 도트 슬롯   │
│        │  워크스페이스 폴더를 고르거나 끌어다 놓으세요 │     애니메이션 │
│        └──────────────────────────────────────────┘                │
│                                                                    │
│        logs/ 가 아니라 그 상위 폴더입니다.                          │
│        여러 개를 넣으면 스쿼드끼리 비교합니다.                       │
│                                                                    │
│        [폴더 고르기]   [파일 고르기]                                │
│                                                                    │
│   ┌────────┐ ┌────────┐ ┌────────┐ ┌────────┐                      │
│   │ ▮ 재생  │ │ ▮ 장부  │ │ ▮ 낭비  │ │ ▮ 비교  │  ← 도트 아이콘 4  │
│   │ 시간순  │ │ 바이트  │ │ 절단선  │ │ 스쿼드  │                    │
│   └────────┘ └────────┘ └────────┘ └────────┘                      │
│                                                                    │
│   ▸ 읽는 파일                                                       │
│                                                                    │
│              Team Monstrous · SEONGHYEON · JUHYEONG · ILKWON       │
└────────────────────────────────────────────────────────────────────┘
```

**바뀌는 것:**

- 배경: 흐르는 간선 → **도트 격자 위를 웨이브가 지나가는 애니메이션.** 실제 스쿼드 맵 형태를 유지하되 도트로 그린다.
- 워드마크: 그라디언트 텍스트 → **인라인 SVG 도트 로고.** 폰트 의존 0.
- CTA: 평범한 버튼 → **코인 투입구 형태.** 드롭 영역이 곧 슬롯이고, 파일을 끌어오면 슬롯이 열린다.
- 카드 4장: 텍스트만 → **도트 아이콘 + 한 줄.**

**바뀌지 않는 것:** 언어 선택이 오프닝에도 있다는 것, 읽는 파일 목록이 접힌 채로 있다는 것, 팀 표기가 맨 아래 흐리게 있다는 것.

## 2. 실행 하나 모드

```
┌─ HUD ──────────────────────────────────────────────────────────────────────────┐
├──────────────┬─────────────────────────────────────────────────────────────────┤
│ [필터][스쿼드]│ [개요][▶재생][장부 대조][타임라인][실패 분류][원문 로그]          │
│ [▤]          │                                                                 │
├──────────────┤ ─────────────────────────────────────────────────────────────── │
│▍math-0041    │                                                                 │
│ ∑ 적격 12k 8s│                          (탭 내용)                              │
│ ▓▓▓▓░░░░░░   │                                                                 │
├──────────────┤                                                                 │
│▍coding-0007  │                                                                 │
│ </> 형식없음 │                                                                 │
│ ▓▓▓▓▓▓▓▓░░   │                                                                 │

```

탭 줄이 HUD에서 내려와 **본문 위**에 붙는다. 좌측 목록 헤더와 같은 높이라 층이 하나 준다.

### 2-1. 좌측 목록 — 카트리지 행

```
┌────────────────────────────┐
│▍ ∑  What is the maximum …  │  ← 계열색 세로 막대 + 트랙 글리프 + 요청 앞 64자
│    ◆적격   AI:GO 3/3       │  ← 판정 도장(작게) + AI:GO 카운트
│    ▓▓▓▓▓▓░░░░  12.4k · 8s  │  ← 토큰 셀 게이지(전체 대비) + 실제 값
└────────────────────────────┘
```

**현행 대비 변화:**

| 현행 | 새 |
|---|---|
| 배지 4개가 가로로 흐름 | 판정 도장 하나 + AI:GO 카운트. **판정이 시각적 주인공** |
| 미니 막대 2줄(토큰·시간)이 각각 3px | 셀 게이지 1줄. 시간은 숫자로만 |
| 트랙 배지가 색 배지 | 도트 글리프 (색 안 씀) |
| 선택 시 `inset 3px` 그림자 | 선택 시 **행 전체가 캐비닛 안으로 눌린 형태** (오프셋 블록 반전) |

**행 높이 68px 고정.** 실행 1,000건에서 가상 스크롤이 가능해야 하므로 가변 높이를 쓰지 않는다.

### 2-2. 아무것도 안 골랐을 때 — 실행 격자

현행: 빈 카드 한 장. 새: **카트리지 격자.**

```
 실행을 고르세요 · 28건 로드됨                    [목록] [격자]

 ┌──────────┐ ┌──────────┐ ┌──────────┐ ┌──────────┐
 │ ∑  ◆적격 │ │</> ◆형식 │ │ ∑  ◆거부 │ │ A? ◆적격 │
 │ 12.4k    │ │ 0 tok    │ │ 0 tok    │ │ 3.1k     │
 │ ▓▓▓▓░░░░ │ │ ░░░░░░░░ │ │ ░░░░░░░░ │ │ ▓░░░░░░░ │
 └──────────┘ └──────────┘ └──────────┘ └──────────┘
 ┌──────────┐ …
```

"기본값 없음" 원칙은 유지된다 — 고른 상태와 안 고른 상태가 완전히 다르게 보인다. 그런데 **처음 여는 사람이 전체 지형을 먼저 본다.** 격자만 봐도 "빨간 게 많네" 가 읽힌다.

### 2-3. 개요 탭

현행은 카드 6장을 세로로 쌓아서 결론이 스크롤 아래로 밀린다. **3층 위계로 재배치한다.**

```
┌───────────────────────────────────────────────────────────────────────────┐
│  이 실행이 무엇을 했고 점수가 되는가                                        │  ← 질문
├───────────────────────────────────────────────────────────────────────────┤
│                                                                           │
│   ┌─────────────┐    채점 적격                          ∑ math            │  ← 결론 층
│   │   ◆         │    finalResult 안에 있습니다           FINAL ANSWER:     │
│   │  적격       │                                        \boxed{<answer>}  │
│   │  GRADED     │    12.4k tok  ·  8.2s  ·  태스크 3/3   웨이브 W1:2 W2:1 │
│   └─────────────┘                                                         │
│                                                                           │
├───────────────────────────────────────────────────────────────────────────┤
│  ⚠ 답은 맞혔는데 보기 문자를 내지 않았습니다                                │  ← 경고 층
│    \boxed{1680} 는 보기 D. $1,680 와 같은 값입니다.                        │     (있을 때만)
│    letter_match 는 값이 아니라 문자 하나를 봅니다. D 한 글자면 점수였습니다.  │
├───────────────────────────────────────────────────────────────────────────┤
│  스쿼드 구성 5명 · 이 실행에서 동작 3명                                     │  ← 근거 층
│  ▮Router  Planner  gpt-oss-120b   참여   3/28  1 태스크   0 실패  41k(추정)│
│  ▮Solver  Solver   K-EXAONE-236B  참여   ...                              │
│  ▮Editor  Developer …             미참여 (디더 처리)                       │
├───────────────────────────────────────────────────────────────────────────┤
│  시간이 어디에 쓰였나                                                       │
│  ████████████ 플래닝 49.0s │ ▒▒▒▒ 승인 대기 20.8s │ ██████ 실행 23.2s      │
├───────────────────────────────────────────────────────────────────────────┤
│  태스크 3                                     (표)                         │
├───────────────────────────────────────────────────────────────────────────┤
│  ▸ AI:GO 자체 요약과 대조                                                  │  ← 각주 층
│  ▸ 워크스페이스에 쓴 파일 4                                                 │     (접힘)
│  ▸ 스쿼드 설정                                                             │
└───────────────────────────────────────────────────────────────────────────┘
```

**핵심 변경 셋:**

1. **판정 도장이 결론 층의 왼쪽 고정 자리.** 스크롤 없이 항상 보인다.
2. **`near` / `hint` 경고가 결론 바로 아래.** 지금은 카드 안 `.note` 문단으로 묻혀 있다. "한 글자 때문에 0점"이 이 도구의 대표 통찰이므로 자리를 올린다.
3. **AI:GO 대조 · 파일 · 설정이 접힌 각주로.** 필요할 때만 편다. 각주가 본문보다 길던 현행을 뒤집는다.

**플래너 폴백 경고**(`plannerWarning`)는 경고 층에 함께 온다. 이건 "문항 하나에 풀 컨텍스트 호출이 에이전트 수만큼 발생한다"는 뜻이라 비용 축과 직결된다.

### 2-4. 재생 탭

현행 구조(컨트롤 → 맵+로그 나란히 → 레인 → 계기)가 이미 좋다. **선택 상태 공유**를 추가하는 것이 이번 변경의 본질이다.

```
│ [▶ 재생] [↺] [8×▾] ├──────────●───────────────────┤  12.4s / 71.2s        │

│   ▮       ▮Router                │ +0.0s  planning-started                │

│ ▸ 에이전트별 토큰은 추정치입니다 (미귀속 3.1k)                              │
└───────────────────────────────────────────────────────────────────────────┘
```

**추가되는 것:**

| 기능 | 지금 | 새 |
|---|---|---|
| 맵 노드 클릭 → 구간 재생 | ✅ | 유지 |
| **레인 막대 클릭** | ❌ | 같은 구간 재생 + 맵 노드 강조 |
| **티커 행 클릭** | ❌ | 그 시각으로 이동 |
| **장부 연결** | ❌ | 태스크 선택 시 장부 대조 탭에 그 태스크가 열린다 |
| 미참여 에이전트 | 점선 + 흐림 | **디더 패턴** — 도트 언어로 통일 |

**계기가 크레딧 게이지를 재사용한다.** HUD의 것과 같은 컴포넌트라 "이 실행이 전체 예산의 얼마인가"가 형태로 읽힌다.

### 2-5. 장부 대조 탭

현행 좌우 2열(요청 원문 / 응답 후보) 구조가 이 탭의 핵심이고 그대로 유지한다. 바뀌는 것은 **검사 결과의 표현**이다.

```
┌───────────────────────────────────────────────────────────────────────────┐
│  채점기가 읽는 바이트를 그대로 보여줍니다                                    │
│  이 문항의 출력 계약: FINAL ANSWER: \boxed{<answer>}                       │
├────────────────────────────────┬──────────────────────────────────────────┤
│ 요청  1,204자                  │ finalResult              ◆ 적격 GRADED    │
│ ┌────────────────────────────┐ │ ┌──────────────────────────────────────┐ │
│ │ …                          │ │ │ …                                    │ │
│ │ ▓=== REQUIRED OUTPUT ===▓  │ │ │ FINAL ANSWER: ▓\boxed{32349}▓        │ │
│ │ ▓FINAL ANSWER: \boxed{…}▓  │ │ │                                      │ │
│ └────────────────────────────┘ │ └──────────────────────────────────────┘ │
│                                │  ✓ \boxed{} 존재       발견 (마지막 사용) │
│                                │  ✓ 중괄호 짝           닫힘              │
│                                │  ✓ 답이 비어있지 않음   "32349"          │
│                                │  ? FINAL ANSWER: 접두사 있음 (권장)      │
│                                ├──────────────────────────────────────────┤
│                                │ Task 1 · Solver          ◆ 부적격        │
│                                │ …                                        │
└────────────────────────────────┴──────────────────────────────────────────┘
```

**바뀌는 것:**

- 검사 항목이 `✓ / ✗ / ?` 세 상태의 **도트 체크 글리프**로. `?`(권장·미확인)가 시각적으로 확실히 구분된다 — 지금은 색만 다르고 모양이 같다.
- 채점 구간 강조(`<mark>`)가 **도트 하이라이트**로. 형광펜이 아니라 캐비닛 조명.
- 도장이 각 응답 후보의 오른쪽 위에 고정.
- 좌우 폭 조절 손잡이 추가 (요청이 60,000자인 coding 문항 대비).

### 2-6. 타임라인 탭

현행 구조 유지 (위상 → 웨이브와 태스크 → 태스크 의존 → 파일 쓰기 → 이벤트 목록).

바뀌는 것:

- **웨이브 띠가 도트 격자 배경**으로. 홀짝 교대 대신 웨이브 번호가 큰 도트 숫자로 박힌다.
- 큐 대기 막대를 흐린 색 대신 **디더 패턴**으로. "이건 실행이 아니다"가 질감으로 읽힌다.
- **파일 쓰기 세로선**에 도트 아이콘. `judge 는 이 파일을 읽지 않는다` 가 툴팁이 아니라 라벨로.
- 이벤트 목록에 `evDetail` 그대로. 다만 **결정 지점 배지**를 붙인다 (`plan-ready` 에 폴백 여부, `task-wave-started` 에 웨이브 번호).

## 5. 상태와 모드

### 5-1. 발표 모드 (`⛶`)

| 현행 | 새 |
|---|---|
| 사이드바 숨김, 글자 15px, 카드 패딩 20px | 같음 + **주변 모션 감쇠** (스캔라인·간선 흐름 정지) |
| | + 크레딧 계기 확대 |
| | + 각주 전부 접힘 |

### 5-2. 고대비 (`◐`)

프로젝터에서 중간 톤이 죽을 때. 새 팔레트는 이미 4.5:1을 넘지만, 고대비는 **7:1 이상**을 목표로 한다.

- 바탕을 순흑/순백으로
- 디더 패턴 제거 (계조가 죽으면 노이즈로 보인다)
- 셀 게이지 간격 2px → 3px

### 5-3. 인쇄 (`🖨`)

현행 `@media print` 유지 + 추가:

- 도트 배경·스캔라인 제거
- 판정 도장을 테두리만으로 (잉크 절약)
- 각주 자동 펼침 (종이에는 접을 수 없다)

### 5-4. 반응형

| 폭 | 배치 |
|---|---|
| ≥ 1400px | 전체 배치. 재생 탭 맵+로그 나란히 |
| 1280 ~ 1400px | HUD 두 띠 유지 (1280에서도 줄바꿈 없음 — 실측) |
| 1100 ~ 1400px | 장부 대조 2열 유지, 차트 격자 2열 |
| 900 ~ 1100px | 장부 대조 1열, 차트 1열, 재생 맵/로그 위아래 |
| < 900px | 좌측 목록 오버레이, HUD 계기 2개만 (실행·크레딧) |

**뷰포트가 아니라 컨테이너 폭으로 접는다.** 창은 넓은데 패널만 좁은 경우가 실제로 있다 — 현행이 `flex-wrap` 으로 푼 것과 같은 이유다.

## 6. 선택 상태 공유 — traceability 장치

```
S.focus = { kind: "task" | "agent" | "time", id, at }
```

이 하나가 바뀌면 네 곳이 반응한다.

| 뷰 | 반응 |
|---|---|
| 스쿼드 맵 | 해당 노드 포커스 링 + 구간 재생 |
| 레인 막대 | 해당 막대 강조, 나머지 감쇠 |
| 이벤트 티커 | 그 시각으로 스크롤 + 행 강조 |
| 장부 대조 | 그 태스크의 응답 후보로 스크롤 |

**설정 경로도 넷이다** — 맵 노드 클릭 / 레인 막대 클릭 / 티커 행 클릭 / 장부의 응답 후보 제목 클릭. 어느 쪽에서 눌러도 같은 상태가 된다.

`Esc` 로 해제. 해제하면 전부 원래대로.

## 7. 화면별 "이 화면이 답하는 질문" — 전부 유지

현행의 가장 좋은 설계다. 새 문구를 적어 둔다.

| 화면 | 질문 |
|---|---|
| 개요 | 이 실행이 무엇을 했고 점수가 되는가 |
| 재생 | 시간과 토큰이 실제로 언제 쓰였는가 |
| 장부 대조 | 채점기가 읽는 바이트가 무엇인가 |
| 타임라인 | 시간이 어디에 쓰였는가 |
| 실패 분류 | 우리 잘못인가 인프라 잘못인가 |
| 원문 로그 | AI:GO 가 실제로 남긴 것이 무엇인가 |
| 전체 분석 | 여기서 끊었다면 얼마를 아끼고 몇 점을 잃었을까 |
| 스쿼드 비교 | 같은 문항을 다른 구성이 어떻게 풀었는가 |

**질문 줄은 모든 패널의 첫 요소다. 어떤 장식도 그 위에 오지 않는다.**
