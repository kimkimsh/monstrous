# 02. 모션 스펙

요구사항은 "애니메이션이 많고"와 "한눈에 쉽게 파악"을 동시에 요구한다. **빈도로 나눠서 푼다.** §5가 이 문서의 핵심이다.

---

## 1. 모션 성격

| 항목 | 값 |
|---|---|
| 원형 | **Playful** (150~300ms, ease-out 계열, 오버슈트) |
| 오버슈트 | **8~12%** — 원형 기본값 10~20%에서 낮췄다. 계기 숫자가 튀면 값이 튀는 것처럼 보인다 |
| 진입 우세 | 진입이 퇴장보다 30~50% 길다 |
| 계단 | 셀 게이지·카운터는 `steps()`. **도트 UI의 정체성** |

---

## 2. 이징 — 네 개뿐

```css
--ease:      cubic-bezier(0.23, 1,    0.32, 1);   /* 진입 · 강한 ease-out. 80%를 담당 */
--ease-pop:  cubic-bezier(0.34, 1.4,  0.5,  1);   /* 도장 · 팝. 오버슈트 12% */
--ease-move: cubic-bezier(0.77, 0,    0.175,1);   /* 화면 안 이동 · ease-in-out */
--ease-exit: cubic-bezier(0.3,  0,    1,    1);   /* 퇴장 전용 · 가속 */
```

**`ease-in` 계열을 진입에 쓰지 않는다.** 시작이 느려서 같은 시간이어도 느리게 느껴진다.
**퇴장은 반대다** — 사라지는 것은 빨리 나가야 뒤가 빨리 보인다. 그래서 `--ease-exit` 하나를 둔다.
쓰는 곳은 셋뿐이다: 오프닝 오버레이 퇴장, 툴팁 사라짐, 도움말 닫기.

**`linear` 는 두 곳만** — 간선 흐름 펄스, 스크럽 중 재생선.
**`ease-in-out` 키워드를 쓰지 않는다.** 필요하면 `--ease-move` 를 쓴다 (`rp-pulse` 가 §4-4에서
그렇게 바뀌었다). 키워드가 섞이면 이징이 다섯 종이 되고, §11 의 검사가 못 잡는다.
**`transition: all` 금지.** 항상 속성을 명시한다.

---

## 3. 지속 시간

```css
--t-press:120ms;   /* 프레스 피드백 */
--t-hover:140ms;   /* 호버 · 색 변화 */
--t-enter:220ms;   /* 진입 */
--t-panel:260ms;   /* 패널 전환 */
```

| 대상 | 지속 | 이징 |
|---|---|---|
| 버튼 프레스 | 120ms | `--ease` |
| 호버 (색·테두리) | 140ms | `--ease` |
| 각주 펼침 | 180ms | `--ease` |
| 셀 게이지 채움 | 220ms | `steps(--cells, end)` |
| 도장 찍힘 | 300ms | `--ease-pop` |
| 패널 진입 | 260ms | `--ease` |
| 모드 전환 | 260ms | `--ease` |
| 오프닝 시퀀스 | 700ms | §6 |
| 툴팁 | 125ms | `--ease` |

**UI 애니메이션은 300ms를 넘지 않는다.** 예외는 오프닝 시퀀스와 재생 자체(사용자가 시간을 조작한다).

## 4. 애니메이션 목록

### 4-1. 셀 게이지 채움

```css
/* @property --on { syntax:'<integer>' } 가 00-디자인-토큰.md §1 에 등록돼 있다 */
.gauge{transition:--on var(--t-enter) var(--ease), --dim var(--t-enter) var(--ease)}
```

칸이 하나씩 켜진다. **연속 보간이면 칸의 의미가 사라진다.**

> **`transition:background … steps()` 는 안 된다.** `background-image` 는 애니메이션 되지 않는
> 속성이라(discrete) 값이 한 번에 튄다. 실측으로 확인했다 — `--on` 5→15 에서 중간 프레임이
> 하나도 없다. `steps()` 를 붙여도 같다. 이징이 아니라 속성이 문제다.
> 값을 `<integer>` 로 등록해서 **값 자체를 애니메이션하면** 보간이 정수로 떨어지므로
> `steps()` 없이도 칸이 하나씩 켜진다 (실측: 5 → 10 → 13 → 15 → 16 → 17).
> 자세한 근거와 대조표는 `01-컴포넌트-스펙.md` §4-1.

### 4-2. 판정 도장

```css
@keyframes stamp-in{
  0%  {opacity:0; transform:scale(1.8) rotate(-14deg)}
  55% {opacity:1; transform:scale(.94) rotate(-6deg)}
  100%{opacity:1; transform:scale(1)   rotate(-4deg)}
}
.stamp{animation:stamp-in 300ms var(--ease-pop) both}
```

`scale(0)` 에서 시작하지 않는다 — **현실에서 아무것도 무에서 나타나지 않는다.**

**부차 동작 하나를 붙인다.** 도장 몸통이 멈춘 뒤 오프셋 블록 그림자가 60ms 늦게 들어온다.
그림자가 같이 움직이면 도장이 종이가 아니라 스티커처럼 보인다.

```css
@keyframes stamp-shadow{ from{box-shadow:0 0 0 currentColor} to{box-shadow:var(--block) currentColor} }
.stamp{animation:stamp-in 300ms var(--ease-pop) both,
                 stamp-shadow 140ms var(--ease) 220ms both}
```

**목록 행 안의 작은 도장에는 애니메이션이 없다** (`j`/`k` 고빈도 경로).

```css
.row .stamp{animation:none}
```

### 4-3. 숫자 카운트업

계기 숫자가 처음 켜질 때만. **값이 갱신될 때는 즉시 바뀐다.**

```js
function countUp(el, to, ms=420, steps=12){
  const from=0, t0=performance.now();
  (function tick(now){
    const p=Math.min(1,(now-t0)/ms);
    const q=Math.floor(p*steps)/steps;          // 계단
    el.textContent=fmt(from+(to-from)*q);
    if(p<1) requestAnimationFrame(tick); else el.textContent=fmt(to);
  })(t0);
}
```

12단 계단이라 아날로그 카운터처럼 보인다. **`prefers-reduced-motion` 이면 즉시 최종값.**

### 4-4. 주변 모션 (`.ambient`)

| 이름 | 지속 | 이징 | 진폭 |
|---|---|---|---|
| 간선 흐름 (`sm-travel`) | 1600ms | `linear` 무한 | 대시 26/974 |
| 실행 중 점 (`sm-blink`) | 1200ms | `steps(2)` 무한 | 불투명도 1 → .35 |
| 실행 중 막대 (`rp-pulse`) | 1200ms | `--ease-move` 무한 | 밝기 1 → 1.25 |
| 스캔라인 | 정지 (움직이지 않음) | — | 불투명도 4% |
| 오프닝 웨이브 | 3600ms | `linear` 무한 | — |

지속 시간을 1,600 / 1,200 / 1,200 / 3,600 으로 **묶었다.** 현행은 1.5 / 1.15 / 1.1 / 3.4 / 2.4 로 전부 달랐다.

`sm-blink` 를 `steps(2)` 로 바꾼 것이 도트 언어다 — 부드럽게 숨쉬는 대신 켜졌다 꺼진다.

```css
html[data-present="1"] .ambient,
html[data-contrast="1"] .ambient{animation:none!important}
```

### 4-5. 패널 진입 — 조건부

```css
.panel{animation:panel-in var(--t-panel) var(--ease) both}
@keyframes panel-in{from{opacity:0;transform:translateY(6px)}to{opacity:1;transform:none}}

/* 고빈도 경로에서는 끈다 — §5 */
.no-anim .panel{animation:none}
```

### 4-6. 목록 stagger — 최초 로드에만

```css
.row{animation:row-in 180ms var(--ease) both}
.row:nth-child(1){animation-delay:0ms}
.row:nth-child(2){animation-delay:40ms}
…
.row:nth-child(n+13){animation-delay:480ms}   /* 12행에서 상한 */
```

**총 stagger가 500ms를 넘지 않는다.** 그리고 최초 로드에만 — 검색·필터로 목록이 바뀔 때는 `.no-anim` 이 걸린다.

## 5. 빈도 등급 — 이 문서의 핵심

| 등급 | 빈도 | 예 | 규칙 |
|---|---|---|---|
| **F0** | 하루 수백 번 | `j`/`k`, `1`~`6` 탭, `m` 모드, 검색 타이핑 | **애니메이션 0.** 즉시 |
| **F1** | 수십 번 | 호버, 프레스, 필터, 각주 접기 | ≤ 180ms, 색·스케일만 |
| **F2** | 가끔 | 마우스로 실행 선택, 패널 진입 | ≤ 260ms |
| **F3** | 드물게 | 오프닝, 재생 시작, 도장, 슬라이더 결과 | 연출 허용 |
| **FA** | 상시 | 스캔라인, 간선 흐름, 맥동 | 저진폭. 시선을 안 끈다 |

### 5-1. F0 구현 — `.no-anim` 플래그

현행의 결함 D-1은 `renderPane()` 이 무엇 때문에 불렸는지를 모른다는 데서 온다. **호출자가 알려준다.**

```js
function renderPane(opts){
  const P=$("#pane");
  document.documentElement.classList.toggle("no-anim", !!(opts&&opts.fast));
  …
}

// 키보드 경로 — 애니메이션 없음
function selectExec(id,{fast=false}={}){ S.sel=id; renderList({fast}); renderPane({fast}); syncHash(); }
addEventListener("keydown",ev=>{
  if(ev.key==="j"||ev.key==="k"||ev.key==="ArrowDown"||ev.key==="ArrowUp"){
    …; selectExec(next.id,{fast:true}); return;
  }
  if(/^[1-6]$/.test(ev.key)){ …; setTab(tab,{fast:true}); return; }
});

// 마우스 클릭 경로 — 애니메이션 있음
li.onclick=()=>selectExec(e.id);
```

```css
.no-anim *,.no-anim *::before,.no-anim *::after{
  animation-duration:0s!important;
  transition-duration:0s!important;
}
```

**같은 함수, 같은 화면, 다른 모션.** 키보드로 훑을 때는 즉시, 마우스로 고를 때는 부드럽게.

### 5-2. 검색 입력

`oninput` 마다 목록이 다시 그려진다. **stagger·진입 애니메이션을 전부 끈다.**

```js
$("#q").oninput=()=>{ renderList({fast:true}); syncHash(); };
```

## 6. 오케스트레이션 — 딱 한 번

폴더를 놓은 직후. **이후로는 `폴더 다시 고르기` 를 눌렀을 때만 재생된다.**

| 시각 | 무엇 | 값 |
|---|---|---|
| 0ms | 오프닝 오버레이 퇴장 | `opacity 1→0`, 160ms, `--ease-exit` |
| 120ms | HUD 내려옴 | `translateY(-100%)→0`, 220ms, `--ease` |
| 240ms | 계기 4개 켜짐 | 60ms 간격 stagger, 각 180ms |
| 240ms | 숫자 카운트업 | 420ms, `steps(12)` |
| 420ms | 좌측 목록 쌓임 | 40ms 간격, 12행 상한, 각 180ms |
| 680ms | 스캔라인 켜짐 | `opacity 0→.04`, 400ms |

**총 700ms.** 진입이 1초를 넘으면 시연에서 기다림이 된다.

퇴장(폴더 다시 고르기)은 **진입의 절반**: 오버레이가 120ms에 뜬다.

## 7. 재생 탭 — 시간 조작은 애니메이션이 아니다

재생은 사용자가 시간을 직접 조작하는 것이라 위 규칙이 적용되지 않는다. 대신:

| 항목 | 규칙 |
|---|---|
| 재생선 이동 | `--p` CSS 변수 + `calc`. **`getBoundingClientRect` 를 쓰지 않는다** (현행 방식 유지) |
| 막대 성장 | `width` 를 매 프레임 갱신. transition 없음 (transition이 있으면 스크럽이 뒤따라온다) |
| 누적 토큰 | **계단.** 보고된 시점에만 오른다. 보간 금지 |
| 노드 상태 전이 | `--nc` 변수 하나만 바꾼다. 테두리·점·글로우·포트가 따라온다 (현행 방식 유지) |
| 티커 행 추가 | 180ms `row-in`. **60fps를 못 지키면 끈다** |
| 프레임 예산 | 16ms. 초과하면 티커 애니메이션부터 버린다 |

### 7-1. 스크럽 되감기

```js
const rewind=to=>{ if(to<RP.t){ RP.shown=0; $("#rp-tick").textContent=""; } RP.t=to; };
```

현행 그대로. 뒤로 감으면 티커를 비우고 다시 채운다.

## 8. 프레스 피드백 — 전부 있어야 한다

현행에는 `:active` 상태가 하나도 없다.

```css
button:active,.card-run:active,.row:active{transform:translate(1px,1px)}
button:active{box-shadow:none}
```

도트 UI라 `scale(0.96)` 대신 **1px 이동**을 쓴다. 오프셋 블록 그림자가 사라지면서 "눌렸다"가 된다. 격자 밖으로 나가지 않는 유일한 프레스 표현이다.

```css
@media (hover:hover) and (pointer:fine){
  button:hover{…}
  .row:hover{…}
}
```

**호버는 미디어 쿼리 안에만.** 터치에서 탭이 호버로 잡히는 것을 막는다.

## 9. 성능 규칙

| 규칙 | 이유 |
|---|---|
| `transform` 과 `opacity` 만 애니메이션 | 레이아웃·페인트를 건너뛴다 |
| `will-change` 는 재생선과 맵 뷰포트에만 | 남용하면 메모리를 먹는다 |
| CSS 변수를 부모에 갱신하지 않는다 | 자식 전부의 스타일이 재계산된다. **재생선은 `.rp-stage` 하나에만 `--p`** |
| 키프레임 대신 트랜지션 | 빠르게 반복되는 상태 변화는 중단·재조준이 돼야 한다 |
| `ResizeObserver` 는 디바운스 | 차트 재생성이 리사이즈마다 돌면 안 된다 (100ms) |

## 10. 감속 (`prefers-reduced-motion`)

**애니메이션을 0으로 만들지 않는다.** 색·불투명도 전환은 이해를 돕는다. 없애는 것은 **이동**이다.

```css
@media (prefers-reduced-motion:reduce){
  *{animation-duration:.01ms!important;animation-iteration-count:1!important;
    transition-duration:.01ms!important;scroll-behavior:auto!important}
  .cabinet::after{display:none}          /* 스캔라인 */
}
```

단, 다음 넷은 감속 상태에서도 유지한다 (정보를 담고 있다):

| 유지 | 대체 |
|---|---|
| 재생선 이동 | 사용자가 조작하는 것이라 애니메이션이 아니다 |
| 셀 게이지 값 변화 | 전환 없이 즉시 반영 |
| 도장 | 애니메이션 없이 바로 표시 |
| 실행 중 표시 | 맥동 대신 **정적 테두리 강조** |
