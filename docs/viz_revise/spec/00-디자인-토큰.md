# 00. 디자인 토큰

`viz/src/app.html` 의 `<style>` 맨 위에 이 블록이 통째로 들어간다. **모든 값은 여기서만 정의되고, 다른 곳에서 리터럴로 쓰지 않는다.**

## 2. 색

### 2-1. 바탕과 글자 — 명암비 검증표

**다크** (`--bg:#17110E` · `--panel:#211812` · `--panel-2:#2C201A`)

| 토큰 | 값 | vs `--bg` | vs `--panel` | vs `--panel-2` |
|---|---|---|---|---|
| `--fg` | `#FFF3E3` | 17.08 | 15.93 | 14.44 |
| `--fg-dim` | `#D8BCA1` | 10.35 | 9.66 | 8.75 |
| `--fg-faint` | `#AB8E76` | 6.11 | 5.70 | **5.17** |

`--fg-faint` 의 최악값 5.17:1 이 하한이다. **현행은 3.25:1 이었다.**

**라이트** (`--bg:#FBF1DF` · `--panel:#FFFAF0` · `--panel-2:#F2E4CC`)

| 토큰 | 값 | vs `--bg` | vs `--panel` | vs `--panel-2` |
|---|---|---|---|---|
| `--fg` | `#241813` | 15.43 | 16.61 | 13.78 |
| `--fg-dim` | `#5C4436` | 8.03 | 8.64 | 7.17 |
| `--fg-faint` | `#71543F` | 6.16 | 6.64 | **5.50** |

**라이트에서 최악의 배경은 `--bg` 가 아니라 `--panel-2` 다.** 첫 산출은 `--bg` 열만 있었고,
그 열만 보면 전부 통과한다. `--panel-2` 를 넣자 CORAL 이 4.49:1 로 떨어졌다 — `04-구현-계약.md` §5-1
의 `PAIRS` 에 `("--coral","--panel-2")` 가 들어 있으므로 **스펙이 자기 검사에서 떨어지는 상태**였다.

### 2-3. 테두리 — 명암비 예외

`--line` (다크 1.57:1 / 라이트 1.52:1) 은 **텍스트가 아니라 구조선**이라 4.5:1 규칙에서 제외된다. 대신:

- 상태를 나타내는 테두리(선택·포커스·경고)는 `--line-strong` 또는 램프 색을 쓴다.
- 고대비 모드에서 `--line` 이 `#8A705E` 로 올라간다 — 순흑 배경 대비 **4.56:1**.

### 2-4. 색 3층 규약 — 위반하면 스펙 위반

| 층 | 어디에 | 표현 | 예 |
|---|---|---|---|
| **1. 판정색** | 채점 판정 4종 | **꽉 찬 배경 + `--ink`** | `채점 적격` 도장 |
| **2. 계열색** | 스쿼드·워크스페이스 | 램프 6색 순환. **선·점·막대에만** | 목록 왼쪽 세로 막대, 산점도 점 |

### 2-5. 판정 4색 매핑 — `verdictOf()` 와 1:1

| `verdictOf(e).k` | 라벨 | 토큰 |
|---|---|---|
| `"ok"` | 채점 적격 | `--v-ok` |
| `"bad"` | 답 형식 없음 | `--v-bad` |
| `"warn"` | 실행 불가 · 계약 미전송 | `--v-warn` |

## 3. 타이포그래피

### 3-1. 7단 스케일 — 이 밖의 값 금지

| 단 | 크기 | 행간 | 굵기 | 자간 | 글꼴 | 쓰는 곳 |
|---|---|---|---|---|---|---|
| `micro` | 10px | 1.3 | 500 | 0 | mono | **SVG 차트 라벨 전용** |
| `caption` | 11px | 1.5 | 400 | 0 | ui | 각주, 보조 설명 |
| `label` | 12px | 1.2 | 700 | .16em | display | HUD 라벨, 배지 (대문자) |
| `body` | 14px | 1.65 | 400 | 0 | ui | 본문, 표 셀 |
| `lead` | 16px | 1.6 | 400 | 0 | ui | **패널의 질문 한 줄** |
| `title` | 20px | 1.3 | 700 | -.01em | ui | 패널 제목 |
| `display` | 32px | 1.05 | 700 | -.02em | mono | **본문 안의 결론 숫자만** — 절단선 결과 3개, 개요 탭 결론 층. **HUD 계기는 `title`(20px)** (§01 §16-0) |

**`micro` 는 SVG 안에서만.** HTML 텍스트의 하한은 `caption` 11px 다.

**`display` 32px 이 서는 자리는 두 곳뿐이다** — 절단선 실험대의 결과 계기 3개, 개요 탭 결론 층.
HUD 계기에 32px 을 쓰면 상단 띠가 90px 로 부푼다. 「가장 큰 것은 언제나 숫자」라는 규칙은
**한 화면 안에서** 성립하면 된다 (`../plan/01-아트-디렉션.md` §7).

### 3-2. 글꼴을 쓰는 자리

| 글꼴 | 자리 |
|---|---|
| `--font-ui` | 문장, 라벨, 표의 텍스트 열, 제목 |
| `--font-mono` | **숫자 열 · 요청/응답 원문 · 코드/마커 · 계기 숫자** |
| `--font-display` | HUD 라벨 (`CREDITS`, `WAVE 2/3`, `GRADED`) |

숫자 열에는 반드시:

```css
font-variant-numeric:tabular-nums;
```

없으면 재생 중 계기 숫자가 흔들린다.

### 3-3. 본문 기본

```css
body{
  font:var(--fs-body)/var(--lh-body) var(--font-ui);
  -webkit-font-smoothing:antialiased;
  text-rendering:optimizeLegibility;
}
h1,h2,h3{text-wrap:balance}
p,.q{text-wrap:pretty}
```

**현행은 `body` 에 `var(--mono)` 를 걸었다.** 스택에 한글 글리프가 없어 한글만 폴백되고 한 줄 안에서 리듬이 깨졌다. 이 한 줄이 이번 개편의 가독성 개선 중 가장 큰 것이다.

### 3-4. 픽셀 폰트 (P2 선택 항목)

| 항목 | 값 |
|---|---|
| 범위 | **라틴 대문자 + 숫자 + 기호만.** 한글 글리프 없음 |
| 형식 | woff2, base64 인라인 |
| 예산 | ≤ 27KB (base64 기준) |
| 적용 | `--font-display` 만 교체 |
| 폴백 | `--font-mono` — 폰트 없이도 설계가 성립해야 한다 |
| 전제 | 오프라인 임베드 재배포 허용 라이선스 확인 |

## 4. 간격과 형태

### 4-1. 4px 격자

`--s1` 4 · `--s2` 8 · `--s3` 12 · `--s4` 16 · `--s6` 24 · `--s8` 32 · `--s12` 48 · `--s16` 64

**모든 `padding` · `margin` · `gap` · `width` · `height` 가 이 여덟 중 하나이거나 그 합이다.** 5px, 7px, 9px, 11px, 13px, 14px 는 스펙 위반이다.

예외 둘:
- `--bd:1px` 테두리
- `--cell-gap:2px` 셀 간격 (4px면 칸이 흩어져 보인다)

### 4-2. 테두리와 그림자

```css
--bd:1px;  --radius:0;  --block:3px 3px 0;
```

| 상황 | 표현 |
|---|---|
| 패널 | `border:var(--bd) solid var(--line)` |
| 떠 있는 것 (팝오버·도장·계기) | `box-shadow:var(--block) var(--line-strong)` |
| 눌린 것 (선택된 목록 행) | `box-shadow:inset var(--block) var(--line-strong)` + `translate(1px,1px)` |
| 강조 (경고 패널) | `border-color:var(--v-warn)` + `box-shadow:var(--block) var(--v-warn)` |

**블러 있는 그림자를 쓰지 않는다.** 도트 UI의 입체는 계단이다.

`--radius:0` 의 유일한 예외: 에이전트 상태 점 (`border-radius:50%`, 지름 8px).

### 4-3. 패턴

**디더** — 비활성·미참여·"실행 아님"

```css
.dither{
  background-image:repeating-linear-gradient(45deg,
    var(--line) 0 1px, transparent 1px 4px);
}
```

**스캔라인** — 캐비닛 바깥 영역에만. `--bg` 위에서만.

```css
.cabinet::after{
  content:"";position:absolute;inset:0;pointer-events:none;
  background:repeating-linear-gradient(0deg,
    rgba(255,243,227,.04) 0 1px, transparent 1px 2px);
}
html[data-contrast="1"] .cabinet::after{display:none}
@media print{.cabinet::after{display:none}}
```

**도트 격자** — 오프닝 배경

```css
background-image:
  radial-gradient(var(--line) 1px, transparent 1px);
background-size:8px 8px;
```

### 4-4. 히트 영역

| 상황 | 최소 |
|---|---|
| 조밀한 데스크톱 (HUD 버튼, 탭) | **40 × 40px** |
| 목록 행 | 68px 고정 높이 |
| 슬라이더 손잡이 | 24 × 24px |
| 맵 노드 | SVG 노드 172 × 62 (현행 유지) |

시각 요소가 더 작으면 `::before` 로 확장한다. **두 요소의 히트 영역이 겹치면 안 된다.**

| 토큰 | 값 | 무엇 |

| `--z-base` | 0 | 본문 |

```css
}
```

**모든 상호작용 요소에 예외 없이.** 현행은 `select`·`button` 에만 있다.

키보드 탐색이 이 도구의 주 조작 경로이므로(`j`/`k`/`1-6`/`m`), 포커스가 안 보이면 조작이 불가능해진다.

## 8. 토큰 검사 — `build.sh` 에 추가

세 검사가 처음에는 틀리게 적혀 있었다. 고친 이유를 같이 적는다.

```bash
# 1. 글자 크기가 7종뿐인가
#    ── 토큰 정의를 센다. 사용처는 전부 var(--fs-*) 라서 'font-size:...px' 로 세면
#       항상 0 이 나와 절대 실패하지 않는 검사가 된다.
grep -oE '^\s*--fs-[a-z]+:[0-9.]+px' src/app.html | sort -u | wc -l      # == 7

#    사용처가 리터럴을 쓰지 않는지 따로 본다 (SVG 속성형 포함).
#    현행 파일에는 SVG 속성형 font-size 가 14개 있다 — 이것도 잡아야 한다.
grep -oE '(font-size:|"font-size":)\s*[0-9.]+' src/app.html | sort -u    # 출력 없어야 함

# 2. 4px 격자를 벗어난 간격이 있는가 (1px 테두리·2px 셀 간격 제외)
#    ── '(padding|margin|gap):' 는 '--cell-gap:2px' 안의 'gap:' 에도 걸린다.
#       자기 토큰을 위반으로 신고하므로 앞에 경계를 넣는다.
grep -oE '(^|[;{ ])(padding|margin|gap|row-gap|column-gap):[^;}]*' src/app.html \
  | grep -oE '[0-9]+px' | sort -u \
  | grep -vE '^(0|1|2|4|8|12|16|24|32|48|64)px$'                # 출력 없어야 함

# 3. border-radius 가 0 이거나 50% 뿐인가
grep -o 'border-radius:[^;]*' src/app.html | sort -u            # 0 · 50% 만

# 4. 인라인 style — 줄이 아니라 선언 개수를 센다
#    ── grep -c 는 '줄 수' 라서 한 줄에 두 개 있으면 하나로 샌다.
#       현행: 선언 89개 / 줄 85개.
grep -o 'style="' src/app.html | wc -l                          # ≤ 20

# 5. transition: all 금지
! grep -q 'transition:all' src/app.html
```

명암비 검사 스크립트는 `04-구현-계약.md` §5-1. **두 문서에 같은 검사가 두 벌 있으면 어긋난다 —
`build.sh` 에 들어가는 정본은 `04-구현-계약.md` §5 한 곳이고, 여기 것은 그 사본이다.**
