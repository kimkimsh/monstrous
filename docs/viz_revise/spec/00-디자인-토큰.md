### 2-3. 테두리 — 명암비 예외

`--line` (다크 1.57:1 / 라이트 1.52:1) 은 **텍스트가 아니라 구조선**이라 4.5:1 규칙에서 제외된다. 대신:

- 상태를 나타내는 테두리(선택·포커스·경고)는 `--line-strong` 또는 램프 색을 쓴다.
- 고대비 모드에서 `--line` 이 `#8A705E`(3.7:1)로 올라간다.

### 2-4. 색 3층 규약 — 위반하면 스펙 위반

| 층 | 어디에 | 표현 | 예 |
|---|---|---|---|
| **1. 판정색** | 채점 판정 4종 | **꽉 찬 배경 + `--ink`** | `채점 적격` 도장 |
| **2. 계열색** | 스쿼드·워크스페이스 | 램프 6색 순환. **선·점·막대에만** | 목록 왼쪽 세로 막대, 산점도 점 |
| **3. 트랙** | coding/math/generic | **색 없음.** `--line-strong` 테두리 + 도트 글리프 + 라벨 | `∑ math` |

```js
// 계열색 — 스쿼드 순서로 고정. 순서가 바뀌어도 같은 스쿼드는 같은 색
const SERIES = ["--ember","--gold","--lime","--magenta","--plum","--coral"];
```

**예외 하나:** 「트랙별」 카드와 트랙 분해 차트 **안에서만** 계열색 램프를 트랙에 빌려준다. 그 문맥에는 판정 배지가 같이 나오지 않는다. 이 예외는 CSS 클래스 `.by-track` 안에서만 유효하다.

### 2-5. 판정 4색 매핑 — `verdictOf()` 와 1:1

| `verdictOf(e).k` | 라벨 | 토큰 |
|---|---|---|
| `"ok"` | 채점 적격 | `--v-ok` |
| `"bad"` | 답 형식 없음 | `--v-bad` |
| `"warn"` | 실행 불가 · 계약 미전송 | `--v-warn` |
| `""` | 판정 보류 · 부분 기록 | `--v-hold` |

`verdictOf` 는 보존 대상 함수다 (`app.html:702`). **매핑만 새로 만들고 함수는 안 건드린다.**

## 3. 타이포그래피

### 3-1. 7단 스케일 — 이 밖의 값 금지

| 단 | 크기 | 행간 | 굵기 | 자간 | 글꼴 | 쓰는 곳 |
|---|---|---|---|---|---|---|
| `micro` | 10px | 1.3 | 500 | 0 | mono | **SVG 차트 라벨 전용** |
| `caption` | 11px | 1.5 | 400 | 0 | ui | 각주, 보조 설명 |
| `label` | 12px | 1.2 | 700 | .16em | display | HUD 라벨, 배지 (대문자) |
| `body` | 14px | 1.65 | 400 | 0 | ui | 본문, 표 셀 |
| `lead` | 16px | 1.6 | 400 | 0 | ui | **패널의 질문 한 줄** |
| `title` | 20px | 1.3 | 700 | -.01em | ui | 패널 제목 |
| `display` | 32px | 1.05 | 700 | -.02em | mono | 계기 숫자, 결론 |

**`micro` 는 SVG 안에서만.** HTML 텍스트의 하한은 `caption` 11px 다.

### 3-2. 글꼴을 쓰는 자리

| 글꼴 | 자리 |
|---|---|
| `--font-ui` | 문장, 라벨, 표의 텍스트 열, 제목 |
| `--font-mono` | **숫자 열 · 요청/응답 원문 · 코드/마커 · 계기 숫자** |
| `--font-display` | HUD 라벨 (`CREDITS`, `WAVE 2/3`, `GRADED`) |

숫자 열에는 반드시:

```css
font-variant-numeric:tabular-nums;
```

없으면 재생 중 계기 숫자가 흔들린다.

### 3-3. 본문 기본

```css
body{
  font:var(--fs-body)/var(--lh-body) var(--font-ui);
  -webkit-font-smoothing:antialiased;
  text-rendering:optimizeLegibility;
}
h1,h2,h3{text-wrap:balance}
p,.q{text-wrap:pretty}
```

**현행은 `body` 에 `var(--mono)` 를 걸었다.** 스택에 한글 글리프가 없어 한글만 폴백되고 한 줄 안에서 리듬이 깨졌다. 이 한 줄이 이번 개편의 가독성 개선 중 가장 큰 것이다.

### 3-4. 픽셀 폰트 (P2 선택 항목)

| 항목 | 값 |
|---|---|
| 범위 | **라틴 대문자 + 숫자 + 기호만.** 한글 글리프 없음 |
| 형식 | woff2, base64 인라인 |
| 예산 | ≤ 27KB (base64 기준) |
| 적용 | `--font-display` 만 교체 |
| 폴백 | `--font-mono` — 폰트 없이도 설계가 성립해야 한다 |
| 전제 | 오프라인 임베드 재배포 허용 라이선스 확인 |

## 4. 간격과 형태

### 4-1. 4px 격자

`--s1` 4 · `--s2` 8 · `--s3` 12 · `--s4` 16 · `--s6` 24 · `--s8` 32 · `--s12` 48 · `--s16` 64

**모든 `padding` · `margin` · `gap` · `width` · `height` 가 이 여덟 중 하나이거나 그 합이다.** 5px, 7px, 9px, 11px, 13px, 14px 는 스펙 위반이다.

예외 둘:
- `--bd:1px` 테두리
- `--cell-gap:2px` 셀 간격 (4px면 칸이 흩어져 보인다)

### 4-2. 테두리와 그림자

```css
--bd:1px;  --radius:0;  --block:3px 3px 0;
```

| 상황 | 표현 |
|---|---|
| 패널 | `border:var(--bd) solid var(--line)` |
| 떠 있는 것 (팝오버·도장·계기) | `box-shadow:var(--block) var(--line-strong)` |
| 눌린 것 (선택된 목록 행) | `box-shadow:inset var(--block) var(--line-strong)` + `translate(1px,1px)` |
| 강조 (경고 패널) | `border-color:var(--v-warn)` + `box-shadow:var(--block) var(--v-warn)` |

**블러 있는 그림자를 쓰지 않는다.** 도트 UI의 입체는 계단이다.

`--radius:0` 의 유일한 예외: 에이전트 상태 점 (`border-radius:50%`, 지름 8px).

### 4-3. 패턴

**디더** — 비활성·미참여·"실행 아님"

```css
.dither{
  background-image:repeating-linear-gradient(45deg,
    var(--line) 0 1px, transparent 1px 4px);
}
```

**스캔라인** — 캐비닛 바깥 영역에만. `--bg` 위에서만.

```css
.cabinet::after{
  content:"";position:absolute;inset:0;pointer-events:none;
  background:repeating-linear-gradient(0deg,
    rgba(255,243,227,.04) 0 1px, transparent 1px 2px);
}
html[data-contrast="1"] .cabinet::after{display:none}
@media print{.cabinet::after{display:none}}
```

**도트 격자** — 오프닝 배경

```css
background-image:
  radial-gradient(var(--line) 1px, transparent 1px);
background-size:8px 8px;
```

### 4-4. 히트 영역

| 상황 | 최소 |
|---|---|
| 조밀한 데스크톱 (HUD 버튼, 탭) | **40 × 40px** |
| 목록 행 | 68px 고정 높이 |
| 슬라이더 손잡이 | 24 × 24px |
| 맵 노드 | SVG 노드 172 × 62 (현행 유지) |

시각 요소가 더 작으면 `::before` 로 확장한다. **두 요소의 히트 영역이 겹치면 안 된다.**

## 5. 층위

| 토큰 | 값 | 무엇 |
|---|---|---|
| `--z-base` | 0 | 본문 |
| `--z-sticky` | 10 | HUD, 탭 줄, 표 헤더 |

`z-index` 리터럴을 쓰지 않는다.

## 6. 포커스

```css
:focus-visible{
  outline:2px solid var(--focus);
  outline-offset:2px;
}
```

**모든 상호작용 요소에 예외 없이.** 현행은 `select`·`button` 에만 있다.

키보드 탐색이 이 도구의 주 조작 경로이므로(`j`/`k`/`1-6`/`m`), 포커스가 안 보이면 조작이 불가능해진다.

## 7. 감속과 인쇄

```css
@media (prefers-reduced-motion:reduce){
  *{animation-duration:.01ms!important;animation-iteration-count:1!important;
    transition-duration:.01ms!important;scroll-behavior:auto!important}
  .cabinet::after{display:none}
}
html[data-present="1"] .ambient{animation:none}
```

`.ambient` 는 주변 모션(스캔라인·간선 흐름·맥동)에 붙는 클래스다. **발표 모드에서 자동으로 멈춘다.**

# 4. 인라인 style 개수
grep -c 'style="' src/app.html                                  # ≤ 20

# 5. transition: all 금지
