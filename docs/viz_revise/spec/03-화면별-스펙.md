# 03. 화면별 스펙 — DOM 구조와 데이터 바인딩

각 화면이 **어느 보존 함수·필드에서 값을 받는지**를 적는다. 새 렌더 코드는 여기 적힌 것만 읽고, 새 계산을 하지 않는다.

표기: `e` = `S.execs` 의 실행 객체 · `X` = 실행 배열 · `sq` = `S.squads` 의 스쿼드

### 1-1. 크레딧 칸 환산

```js
const CREDIT_CELLS=20;
function creditScale(total){
  const raw=total/CREDIT_CELLS;
  const mag=Math.pow(10, Math.floor(Math.log10(Math.max(1,raw))));
  return Math.ceil(raw/mag)*mag;          // 유효숫자 1자리로 올림
}
```

표시: `1칸 = ${fmt(unit)} tok`. **환산값을 화면에서 빼면 안 된다.**

환산 비율은 **총 토큰에서 유도한다.** 어디에도 고정 숫자를 적지 않는다 — 기획 문서 두 곳이
한때 `1칸 = 1,000 토큰` 으로 못 박아 두었는데, 실측 총량 1.24M 에 20칸이면 칸당 62k 라서
100배가 틀린 값이었다. **`creditScale()` 이 유일한 정본이다.**

### 1-2. 절단선 연동

`S.cut` 이 유한하면:

```js
const kept = X.filter(e=>billed(e)<=S.cut).reduce((s,e)=>s+billed(e),0)
           + X.filter(e=>billed(e)>S.cut).length * S.cut;
gauge.style.setProperty("--on",  Math.round(kept/unit));
gauge.style.setProperty("--dim", Math.round((total-kept)/unit));

```

`--dim` 구간은 디더로 남는다. **원래 값이 사라지면 실험이 실험으로 안 읽힌다.**

### 1-3. 시간 표기 — 전용 포맷터가 필요하다

현행에는 시간 포맷터가 `secs(ms)` 하나뿐인데, 이건 `(ms/1000).toFixed(1)+"s"` 라서
**초만 낸다.** 실행 하나에는 맞고 전체 합계에는 안 맞는다 — 28건 합계가 `1960.0s` 로 나온다.
`fmt()` 는 개수용이라 `17.4M` 처럼 단위 없는 접미사를 붙인다. 둘 다 HUD 의 TIME 계기에 못 쓴다.

**새 순수 함수를 하나 만든다.** 보존 구간이 아니므로 신규 코드다.

```js
// 총 wall-clock 표기. secs() 는 실행 하나에 그대로 두고, 합계에만 이걸 쓴다.
function dur(ms){
  if(ms==null) return "—";
  const s=ms/1000;
  if(s<60)    return s.toFixed(1)+"s";
  if(s<3600)  return Math.floor(s/60)+"m "+Math.round(s%60)+"s";
  return Math.floor(s/3600)+"h "+Math.round((s%3600)/60)+"m";
}
```

TIME 계기의 `.stat-d` 는 `평균 ${secs(총합/실행수)}`. **평균은 실행 하나 단위라 `secs` 가 맞다.**

### 4-2. 0점 4분류 스택

```js
const B={blocked:0, nocontract:0, markers:0, unknown:0, ok:0};
for(const e of X) e.gradable ? B.ok++ : B[e.blocker]++;
```

| 구간 | 색 | 하단 라벨 |
|---|---|---|
| 호출 거부 | `--v-warn` | 설정 |
| 계약 미전송 | `--v-warn` | 러너 |
| 판정 보류 | `--v-hold` | 검사기 |
| 답 형식 없음 | `--v-bad` | **프롬프트** |
| 채점 적격 | `--v-ok` | — |

**구간은 다섯이다.** 이름이 「0점 4분류」인 것은 0점이 네 갈래라는 뜻이고, 막대에는
비교 대상인 채점 적격이 같이 선다. `판정 보류` 가 0건이면 그 구간은 렌더하지 않는다 —
`02-데이터-원천과-한계.md` §2 「없는 값에는 카드를 세우지 않는다」와 같은 규칙이다.

두 warn 구간을 인접시키고 사이에 `--bg` 1px 구분선을 둔다. **같은 색이지만 다른 사람이 고친다**는 것이 하단 라벨로 갈린다.

## 6. 상태 모드

### 6-1. 발표 (`data-present="1"`)

```css
html[data-present="1"]{--fs-body:16px;--fs-lead:18px;--fs-title:24px;--fs-display:40px}
html[data-present="1"] .side{display:none}
html[data-present="1"] .ambient{animation:none!important}
html[data-present="1"] .fn[open]{--force-closed:1}   /* JS로 접는다 */
```

토큰 자체를 키우므로 **레이아웃이 자동으로 따라온다.** 현행처럼 개별 규칙을 나열하지 않는다.

### 6-2. 고대비 (`data-contrast="1"`)

`00-디자인-토큰.md` §1의 블록. 추가로:

```css
html[data-contrast="1"] .dither{background-image:none;background:var(--panel-2)}
html[data-contrast="1"] .cabinet::after{display:none}
```

**디더를 제거한다.** 계조가 죽은 화면에서 디더는 정보가 아니라 노이즈다.

### 6-3. 인쇄

```css
@media print{
  /* 색은 body 가 아니라 토큰에서 뒤집는다. body 만 흰색으로 바꾸면 패널이 --panel 을
     그대로 써서 검은 종이가 되고, 브라우저가 배경 인쇄를 끄면 이번엔 --fg 가 흰 종이
     위에 남아 아무것도 안 보인다. tools/contrast.py 가 이 블록도 같이 검사한다. */
  :root{
    --bg:#FFFFFF; --panel:#FFFFFF; --panel-2:#FFFFFF;
    --line:#999999; --line-strong:#000000;
    --fg:#000000; --fg-dim:#241813; --fg-faint:#5C4436;
    --ink:#FFFFFF;
    --ember:#AF3B09; --gold:#865A00; --lime:#3F6A0B;
    --coral:#B92D24; --magenta:#B12B75; --plum:#7A3DAF;
  }
  .hud-nav,.hud-2,.side,.splitter,.drop,.cut-ctl,.sm-zoom,.help,.rp-ctl{display:none!important}
  .panel{break-inside:avoid;box-shadow:none}
  .stamp{box-shadow:none;transform:none}
  details{display:block} details > *{display:block!important}
  html,body{height:auto;overflow:visible}
  /* 채움이 곧 값인 것들 — 막대 길이 · 칸 수 · 소유권 구간.
     브라우저의 "배경 그림 인쇄"가 꺼져 있어도 이것만은 나와야 한다. */
  .stack > div,.phases > div,.phases > div > span,.rp-phases > div,.rp-phases > div > span,
  .gauge,.rp-bar,.rp-wait,.legend i,.sm-key i,.row-bar,.sq-card .bar{
    -webkit-print-color-adjust:exact;print-color-adjust:exact}

```

**인쇄에서 토큰을 안 뒤집으면 종이가 검게 나오거나 아예 비어서 나온다.** 초안은 `body` 에만
`background:#FFFFFF; color:#000000` 을 걸어 두었는데, 패널·표·HUD 는 자기 배경을 토큰에서
가져오므로 그대로 어둡게 남는다. 배경 인쇄를 끈 기본 설정에서는 반대로 흰 종이 위에
`--fg`(#FFF3E3) 글자만 남아 백지가 된다. 실제 PDF 로 확인했다.

## 8. 단축키 도움말 — `alert` 대체

```html
<div class="help" id="help" hidden role="dialog" aria-modal="true" aria-label="단축키">
  <table>…9행…</table>
  <p class="fn">Esc 로 닫습니다</p>
</div>
```

| 키 | 동작 |
|---|---|
| `j` / `↓` | 다음 실행 |
| `k` / `↑` | 이전 실행 |
| `1`~`6` | 탭 전환 |
| `m` | 모드 순환 |
| `/` | 검색 |
| `b` | 목록 접기 |
| `?` | 이 도움말 |
| `Esc` | 선택 해제 · 입력 빠져나오기 · 도움말 닫기 |
| 휠 / 드래그 | 맵 확대 · 이동 |

**`?` 는 F0(고빈도)이 아니므로 진입 애니메이션을 허용한다.**
