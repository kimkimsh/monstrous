# viz_revise / spec — 스펙

`viz/src/app.html` 재작성의 **정확한 값**이다. 기획(`../plan/`)이 "왜"와 "무엇을"을 적었다면, 여기는 "얼마나"를 적는다.

**값이 기획과 스펙 양쪽에 있으면 스펙이 정본이다.** 구현 중에 값이 바뀌면 스펙을 고친다.

## 값이 지켜야 할 불변식 여섯

이 여섯 중 하나라도 깨지면 스펙 위반이다.

1. **모든 텍스트 색은 자기 배경 대비 4.5:1 이상.** 고대비 모드는 7:1 이상.
2. **글자 크기는 7종뿐.** 그 밖의 값은 스펙 위반.
3. **모든 간격·크기는 4의 배수.** 예외 없음.
4. **`border-radius` 는 0.** 원형 상태 점만 예외.
5. **고빈도 경로(`j`/`k`·탭·검색)에 애니메이션 0.**
6. **색은 3층 규약을 벗어나지 않는다.** 판정색 · 계열색 · 트랙은 무채.
