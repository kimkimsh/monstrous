01 The shape · why not one

One seat the app forced. One seat arithmetic asked for.

{{glyph:router:24}} The planner seat is nailed downplatform

Only the planner sees the request in full. Workers receive the description of the task the planner wrote and nothing else. We cannot delete the seat, so we shrank its job: Router calls create_task once and stops.

{{glyph:coder:24}} Coder and Solver split on lengtharithmetic

Coder's contract runs to 7,698 characters, most of it the patch format the parser enforces. Merge the two seats and every math item carries those rules past a parser it will never reach.

Charged on 109 of 147 items
Coding request, median 63,812 B across the 20 published coding requests

Head count is a multiplier when things go wrong. If the planner call fails, the app stops splitting the request and hands the full text to every agent. At that median, each extra seat costs another 63,812 bytes of input on one coding item.
