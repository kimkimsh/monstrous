The rule reads the shape of the block, so there is no room for the model to guess a track. Every request ends with one of these four.

Never calls check_task_status · aggregate_results · update_plan
It copies, it does not summarise

A rewritten problem is a different problem. An options list that was not copied has no letter to choose. A retyped source line is a patch that will not apply.

Coding is the one exception

Repository context runs to about 60,000 characters and will not fit. Issue text first, then excerpts strongest-first, then the block. It stops at about 32,000 characters and drops a whole excerpt rather than cutting one.

Excerpt ranking, strongest first
  1. A path the issue names outright
  2. A path in the traceback the issue pasted
  3. An excerpt defining a symbol the issue called
  4. An excerpt calling that symbol

Anything past the fourth is a guess, and one guess spends about 12,000 characters.

02 The contracts · Solver

Solver carries 109 of the 147 items.

{{glyph:math:20}}Mathematics

Solve to a value, then check it a second way — substitute back, re-derive one step along another path, or try the smallest case. When the two disagree, take the one you can justify.

No averaging, and never both answers. Sign, integrality, range, and extraneous roots get checked.

{{glyph:generic:20}}Multiple choice

Solve before looking at the options. Picking an option first and reasoning toward it is how a wrong option wins.

Option counts run from three to ten and are not always A through J. A letter absent from that item's own Options block scores zero however good the reasoning.

{{glyph:generic:20}}Everything else

The graded benchmarks are three, but the harness can send something outside them. A squad that knows only three tracks forces a shape onto the fourth and loses a correct value to formatting.

There the sentence in which the request states its own answer shape is the contract.

Three ways the last line breaks
Before the value
bold marks, a bullet, a quote arrow
After the value
an option name, brackets, a full stop, two letters
Wrong case
the pattern is anchored to the whole line

02 The contracts · who verifies

We did not delete the verifier. We moved it into two places.

{{glyph:ok:22}} Inside the agent's own turnno extra call
  • Solver's second derivation of the same value
  • Coder's sibling-caller check before it writes
  • The final-line rules, applied by the seat that writes the line

All of it runs inside one response, so the call count does not move.

Model calls added0
{{glyph:ok:22}} A program, at build timetools/validate_template.py

The build feeds our six prompt texts to the grader's own extractors — extract_letter, extract_boxed, extract_patch. If any of them pulls an answer out, no artifact is produced.

If the grader can find an answer in our instructions, then the moment a model leaks a fragment of those instructions, the fragment is what gets graded.
Conditions enforced50
Human review needed none

Why not one more verification hop. The grader reads only the last task, so a verification hop becomes the last hop, and that seat is not the one that produced the answer. Beyond that, self-verification with no external signal moved GPT-4 on GSM8K from 95.5% to 89.0%, while deterministic supervision raised SWE-bench resolve rate by 9.9% on average. We took the second one.

03 Giving up, and the budget

There is no cap to stop before. So giving up means not making the call.

Hidden-set caps, from the leaderboard API

no wall-clock cap,
no token cap

Both fields come back null on every graded run. Nothing throttles a run from outside, so every call we make is a call we chose.

The plan graph freezes before the run starts and carries no conditional branch, so this cannot be an agent making a judgment call. It has to be four rules, each sitting where it can still act.

01 · Router

One task, no re-planning. The app's own planner instruction says split as small as possible; we reversed it. One task is one model call.

02 · Copy budget

32,000 characters, filled strongest-first. If create_task returns a length error, drop the excerpts and call again. Issue text alone still scores; a missing task scores zero.

03 · The worker

When a derivation runs long, stop and write the answer line with the best value held so far. A truncated response has no answer line at all — the only way we lose an item already solved.

04 · Never answer empty

This one reversed. With several waves an empty output is safe, because the grader skips back. With one wave there is no net. Empty is a certain zero; a guess is sometimes right.

The budget file is not part of the submission. budget.json is a local squad budget and never reaches the evaluation server, which runs on runtime defaults (maxTasksPerPlan 20, maxAgentTurns 20, maxPlanIterations 3). That is why all four rules live in prompts rather than settings.
