04 The viewer · the fault that never happened

The tool's most useful finding was its own miscount.

For a while the screen carried a branch called contract not sent. If the recorded request had no === REQUIRED OUTPUT === section, we read that as the runner failing to send the contract, and we were charging 8 runs to the runner on that basis.

Evidence one · it never fit
Those 8 request fields 83–499 chars
A contract section ~250 chars

There was no room for one to have been there. history.json stores the question only, not the prompt the model was handed.

Evidence two · the model heard it

6 of 8 responses contained \boxed{}. One went all the way to FINAL ANSWER:.

A model cannot follow a contract it was never sent. The branch described something that had not happened.

Write the log's silence down as an event and you invent a fault nobody committed. That is the one thing this tool must never do, so the branch came out.

04 The viewer · why the screen can be trusted

If it is not in the log, we do not draw it.

Deliberately absent

Cache hit rate, cost per model, tokens per task, confidence curves. The platform's per-agent token fields come back all zero. Drawing them would be inventing numbers.

Labelled where it is inferred

Per-agent tokens are an estimate and the screen says so, in place, with the reason. Cut-line figures are an upper bound on loss, because every truncated run is counted as lost outright. That sentence is on the screen too.

Replay is labelled three ways, and they are never mixed
Observed replay

Exactly what happened, in the order it happened.

Prefix stop simulation

A recorded run, cut short at a chosen point.

Assumption-bound policy simulation

A changed policy, with the remainder filled in by estimate.

Nothing that did not run is ever drawn as though it ran.

Logic moved byte for byte 1,105 lines

We replaced the entire interface and changed no data. Parsing, verdicts, aggregation, loading and export were carried over unchanged, and the build diffs them against the original every time. One line of drift and no artifact is produced. Same folder in, byte-identical JSON out.

A Appendix · claims we do not make

Things that would sound good and are not true.

Not saidBecause
“This design raised our score” There is no graded result yet. What we can say is what we measured and which design decision each measurement produced
“Requests fell from 1,192 to 294” 294 is a projection: measured practice sizes multiplied by hidden item counts. The documents label it a projection too
“We have an agent that decides to give up” Not buildable. The plan graph freezes before the run and has no conditional branch
“Prefix caching saves us tokens” It saves latency. vLLM bills cache hits into prompt_tokens in full, and the documentation says it returns prefill time
“Coder runs at high reasoning effort” The template has no way to set effort per agent, and writing the line into a system prompt does not work either
“22 disabled tools locked the agents down” The squad execution path does not read that field. The handle that works is the empty enabledTools
“Here are per-item traces from a graded run” The portal does not break runs down per item, and no path to re-read hidden response bodies has been confirmed. The viewer earns its keep on development runs
