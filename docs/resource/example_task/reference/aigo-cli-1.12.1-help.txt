
########## aigo bench
Benchmark management

Usage: aigo bench <COMMAND>

Commands:
  run      Run a new benchmark
  cancel   Cancel the currently running benchmark
  state    Show the current benchmark state
  history  Show benchmark history
  show     Show details for a specific benchmark
  delete   Delete a benchmark result
  compare  Compare two or more benchmarks side by side
  export   Export benchmark data
  help     Print this message or the help of the given subcommand(s)

Options:
  -h, --help  Print help

===== aigo bench run
Run a new benchmark

Usage: aigo bench run [OPTIONS]

Options:
  -m, --model <MODEL>
          Model ID to benchmark (omit to benchmark the currently loaded model)
      --prompt-tokens <PROMPT_TOKENS>
          Number of prompt tokens
      --completion-tokens <COMPLETION_TOKENS>
          Number of completion tokens to generate
  -c, --concurrency <CONCURRENCY>
          Number of concurrent requests
      --warmup <WARMUP>
          Number of warmup iterations
  -n, --iterations <ITERATIONS>
          Number of benchmark iterations
  -h, --help
          Print help

===== aigo bench cancel
Cancel the currently running benchmark

Usage: aigo bench cancel <ID>

Arguments:
  <ID>  Benchmark ID to cancel

Options:
  -h, --help  Print help

===== aigo bench state
Show the current benchmark state

Usage: aigo bench state

Options:
  -h, --help  Print help

===== aigo bench history
Show benchmark history

Usage: aigo bench history [OPTIONS]

Options:
  -m, --model <MODEL>  Filter by model ID
  -h, --help           Print help

===== aigo bench show
Show details for a specific benchmark

Usage: aigo bench show <ID>

Arguments:
  <ID>  Benchmark ID

Options:
  -h, --help  Print help

===== aigo bench delete
Delete a benchmark result

Usage: aigo bench delete [OPTIONS] <ID>

Arguments:
  <ID>  Benchmark ID

Options:
  -y, --yes   Skip confirmation prompt
  -h, --help  Print help

===== aigo bench compare
Compare two or more benchmarks side by side

Usage: aigo bench compare <IDS> <IDS>...

Arguments:
  <IDS> <IDS>...  Benchmark IDs to compare (at least two required)

Options:
  -h, --help  Print help

===== aigo bench export
Export benchmark data

Usage: aigo bench export [OPTIONS]

Options:
  -f, --format <FORMAT>  Output format (json or csv) [default: json]
  -h, --help             Print help

===== aigo node request
Request a connection key from a remote node and register it.

Performs POST /nodes/register/request which only returns a connection key; to complete registration in a single step use `node add-discovered` or call `node register` with the returned key.

Usage: aigo node request <TARGET> [PORT]

Arguments:
  <TARGET>
          Remote target as `host port`, `host:port`, or full URL

  [PORT]
          Remote port when `target` is a bare host name

Options:
  -h, --help
          Print help (see a summary with '-h')

===== aigo node add-discovered
Register a peer from a discovered node entry (completes request + register in one step)

Usage: aigo node add-discovered <TARGET> [PORT]

Arguments:
  <TARGET>  Discovered node fingerprint (full or unique prefix), or a direct `host port`, `host:port`, or full URL target
  [PORT]    Remote port when `target` is a bare host name

Options:
  -h, --help  Print help

          Start of date range. Accepts RFC 3339 (e.g. `2026-04-01T00:00:00Z`) or a plain `YYYY-MM-DD` date, which is normalized to `T00:00:00Z` client-side before being sent. Relative day forms `today`, `yesterday`, and `<Nd>` (e.g. `7d`) are also accepted

########## aigo chat
One-shot chat completion

Usage: aigo chat [OPTIONS] [MESSAGE]

Arguments:
  [MESSAGE]
          Message to send (reads from stdin if not provided)

Options:
  -m, --model <MODEL>
          Model to use for completion

      --max-tokens <MAX_TOKENS>
          Maximum tokens to generate
          
          [default: 1024]

      --temperature <TEMPERATURE>
          Sampling temperature (0.0-2.0)
          
          [default: 0.7]

  -s, --system <SYSTEM>
          System prompt to prepend

      --reasoning-effort <LEVEL>
          Reasoning effort level for reasoning models; use "none" to disable thinking mode
          
          [possible values: none, low, medium, high, xhigh]

      --no-think
          Disable thinking mode (sets chat_template_kwargs.enable_thinking=false); takes precedence over --reasoning-effort

      --thinking-budget <N>
          Per-request cap on tokens inside the `<think>` block.
          
          Matches llama.cpp / mlxcel-server / vLLM semantics: -1 = unlimited, 0 = immediate end, N > 0 = hard cap of N tokens. Sent as the per-request body field `thinking_budget_tokens`, which is engine-agnostic (works on both llama-server and mlxcel-server).

      --preserve-thinking
          Preserve `<think>` blocks from all prior assistant turns (Qwen3.6+).
          
          Sets `chat_template_kwargs.preserve_thinking=true`. Orthogonal to `--reasoning-effort` / `--no-think`: both `enable_thinking` and `preserve_thinking` coexist in the same kwargs object when flags are combined. Older Qwen3/3.5 models accept the flag but the behavior is unvalidated.

  -h, --help
          Print help (see a summary with '-h')
