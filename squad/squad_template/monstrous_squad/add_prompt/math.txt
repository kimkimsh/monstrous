WHAT IS GRADED

HOW TO WORK

1. Work the problem to a value. Do not restate the problem, do not explain your method, and do not
   narrate what you are about to do — none of it is read.

2. Check the value a second way before you commit to it. Pick whichever fits: substitute it back
   into the original condition, re-derive one step by a different route, test the smallest or a
   degenerate case, or check it against a bound you can establish independently. If the two routes
   disagree, take the one you can justify. Do not average them and do not present both.

3. Check sign, integrality, range, and extraneous roots. Competition problems are written so that
   a plausible-looking wrong branch exists; most wrong answers are a real derivation that kept one.

4. If the problem states the shape of its own answer — an integer range, a unit, a number of
   decimal places, "express in simplest form" — that is a constraint the value has to satisfy. A
   value that fails it is the wrong value, not a formatting problem. Go back to step 1.

5. Write the answer in the representation the problem asked for. A reduced fraction stays a
   fraction. Radicals stay in surd form. Angles stay in the unit the problem used. If the problem's
   own answer form carries a currency symbol, a unit, an interval, a set, or a mixed number, keep
   it. If the answer is a plain integer, write the bare integer with no thousands separators and no
   units. Nothing but the value goes inside the braces — no words, no `\text{}`, no explanation.

THE OUTPUT CONTRACT

The REQUIRED OUTPUT block at the end of this message gives the exact final line. Three things
break the match, and each of them scores zero with a correct value:

- Something before the prefix on that line: bold markers, a list bullet, a blockquote arrow, a

- Something between the colon and the opening of the box other than spaces — a dollar sign
  wrapping the box is the common one.
- The wrong case. The prefix is compared literally, capitals included.

Braces must balance: a fraction inside the box is fine, an unclosed brace is not.

Write that line once, at the very end, and write nothing after it. If more than one appears, only
the last is read.

Always write it. A reply with no final line extracts nothing and scores zero; a committed value can
score. Never present two candidates and never hedge.
